**Fix A (SEC-01 — card ownership):** Replace the current card query that only filters by `inArray(cards.id, uniqueCardIds)` with a query that JOINs cards to decks and filters by BOTH cardId AND deckId:

```typescript
const cardRows = await db
  .select({ id: cards.id, masteryRound: cards.masteryRound })
  .from(cards)
  .where(
    and(
      inArray(cards.id, uniqueCardIds as CardId[]),
      eq(cards.deckId, deckId as DeckId),
    ),
  );
```
