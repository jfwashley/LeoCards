## Decisions Made

- `firstDeck === undefined` (not `decks.length === 0`) is the zero-deck check in `loadDashboardCore`, so the SAME statement both triggers the onboarding early return and narrows `firstDeck` for the `decks.find(...) ?? firstDeck` fallback — removing the need for a second, practically-unreachable guard.
- `dashboard.test.ts` mocks the three query-helper modules directly (not `@/db`) so `deriveStudySubset` runs for real inside the test, proving the actual composition rather than re-implementing it in fixtures.
- `route.test.ts` mocks `@/lib/core/dashboard` wholesale per the plan's own test-split guidance — DB-shaped behavior is asserted once, in `dashboard.test.ts`.
- `page.tsx`'s active-deck resolution is one `.find()` + one `if (!activeDeck) return null`, since a missing match and a `null` `activeDeckId` both resolve to `undefined`.
