## Sampling Rate

- **After every task commit:** that task's own `<automated>` command — always a scoped
  `npx vitest run <paths>` plus `npx tsc --noEmit`, and `npx tsc -p packages/domain --noEmit`
  whenever the shared package was touched
- **After any Biome fix pass:** full `npx tsc --noEmit` (AGENTS.md — Biome's no-non-null-assertion
  rule has previously pushed code into shapes tsc rejects under `noUncheckedIndexedAccess`)
- **After every plan wave:** `npx vitest run` (full) + `npm run build`
- **After any wave touching the SRS/study path** (waves 3 and 4): `npm run qa:run` — 5/5 journeys,
  zero residue
- **After any wave touching the dependency graph** (waves 1, 3, 6): `npm ci` — proves the committed
  lockfile is exactly what Vercel and CI will install
- **Before `/gsd:verify-work`:** full suite green (four flakes re-verified in isolation) plus a
  committed post-deploy `npm run perf:recert` report
- **Max feedback latency:** ~90 seconds (full suite); ~15 seconds for a scoped per-task run
