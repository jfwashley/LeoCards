**Analog requiring the zod/mini rewrite (Pitfall 6):** `src/app/api/translate/route.ts` lines 26-43:
```typescript
const RequestSchema = z
  .object({
    text: z.string().min(1).max(500).optional(),
    texts: z.array(z.string().min(1).max(500)).min(1).max(50).optional(),
    sourceLang: z.enum(["en", "fr", "es"]),
    targetLang: z.enum(["en", "fr", "es"]),
  })
  .refine((v) => (v.text !== undefined) !== (v.texts !== undefined), {
    message: "Provide exactly one of text or texts",
  });
```
`.refine()` as a chainable method **does not exist on zod/mini's `z.object()`** (verified live against installed `zod@4.3.6` in Phase 27-07). The already-proven-in-this-repo replacement, copied verbatim from `src/components/change-password-card.tsx` lines 17-28:
```typescript
import * as z from "zod/mini";

const changePasswordSchema = z
  .object({
    currentPassword: z.string().check(z.minLength(1, "Current password is required")),
    newPassword: z.string().check(z.minLength(8, "Password must be at least 8 characters")),
    confirmNewPassword: z.string().check(z.minLength(1, "Please confirm your new password")),
  })
  .check(
    z.refine((data) => data.newPassword === data.confirmNewPassword, {
      message: "Passwords do not match",
      path: ["confirmNewPassword"],
    }),
  );
```
The rule: `.object({...}).refine(fn, opts)` → `.object({...}).check(z.refine(fn, opts))`. Apply this exact rewrite to `RequestSchema` if/when it's extracted into `packages/domain/src/schemas/translate.ts`.

**New endpoint schemas (dashboard/study-load/cards-create/account):** no existing schema to copy verbatim (these are genuinely new request/response shapes) — but every new schema should follow the same allow-listed-fields, `.min()/.max()`-bounded-string convention visible in both examples above (V5 / T-26-01 discipline — "Over-posting" threat pattern in RESEARCH's Security Domain section).

import { and, eq } from "drizzle-orm";

import type { NextRequest } from "next/server";

const someLimiter = createRateLimiter({ windowMs: 60_000, maxRequests: 30 });

export async function POST(/* or GET, per endpoint */) {
  const session = await auth.api.getSession({ headers: await headers() }); // raw call, NOT getSession()/getSessionFresh()
  if (!session) return Response.json({ error: "Unauthorized" }, { status: 401 });

  const limit = someLimiter.check(session.user.id);
  if (!limit.allowed) {
    return Response.json({ error: "Too many requests" }, {
      status: 429,
      headers: { "Retry-After": String(Math.ceil(limit.retryAfterMs / 1000)) },
    });
  }

  // ownership: single SELECT ... innerJoin ... where(and(eq(id), eq(userId))) — 403 never 404
  // business logic — call packages/domain functions, never re-implement
  return Response.json({ /* raw data, no envelope wrapper */ });
}

  const session = await auth.api.getSession({ headers: await headers() });

  const deckRows = await db.select().from(decks).where(eq(decks.id, deckId as DeckId));
