**`npm run qa:run`** runs `node scripts/qa-run.mjs` (the Phase 15 harness, QAJ-01..06). Per its
header block it needs a dev server started with `STUDY_COOLDOWN_MINUTES=1` plus `DATABASE_URL` and
`DEBUG_CHEAT_SECRET` in the environment. Restart a FRESH dev server first (AGENTS.md E2E hygiene —
never reuse a long-lived one; Phase 25-04 hit a stale-404 from exactly that mistake). All QA users
use the `*test.local` domain so `scripts/cleanup-test-users.mjs` removes them (QAJ-06); a run must
leave no residue. It drives the app's own API path, never the `/debug` virtual override.

**`npm run perf:recert`** runs `node scripts/perf-recert.mjs` (Phase 18, PERF-06). Two halves, run
strictly sequentially: a warm-**prod** Lighthouse CWV pass over the four key routes, and a nav-gate
half that builds a local prod build, starts `next start`, and runs `e2e/13-perf.spec.ts` under
`PERF_PROD_BUILD=1` against the 850ms D-12 gate. Roughly 40 minutes. Needs `DATABASE_URL`. Writes a
dated report to `.planning/phases/18-field-validation-guardrails/measurements/` as
`recert-<YYYY-MM-DD>-<HHmm>.md` and `.json` plus per-route `cwv/` artefacts, and exits non-zero on
a red gate.

Because its CWV half measures **deployed production**, running it before the deploy would certify
the OLD build. It must therefore run AFTER the push. AGENTS.md's cadence rule says exactly this:
run it after any deploy that touches perf-relevant surfaces — and this phase touches
`next.config.ts` (`transpilePackages`), the shared dependency graph, and two of the four perf-gated
key route pages (`/dashboard`, `/study`).

`measure-cwv.mjs` has a bundle-freshness gate that fails when `.next` predates HEAD. Phase 18-05
lost two runs to exactly this by committing between builds — so do not commit anything between
starting a `perf:recert` run and its completion.

**Known-tolerable unit-test noise:** four documented parallel-execution flakes — `deck-switcher`,
`image-upload-flow-extract-errors`, `review-list-commit-guard`, `cooldown-config`. Each passes in
isolation. Any OTHER failure is real.
