<objective>
Stop committing reviewed image-cards one server-action-call-per-row. Today `commitReviewRows` loops N rows and calls `saveImageCards(deckId, [singleCard])` N times — each call re-runs `auth.api.getSession()` + the deck-ownership SELECT + a single-row insert. Convert to ONE `saveImageCards(deckId, allRows)` call whose internal loop becomes a single multi-row `.values([...])` insert (auth/ownership checked once), mirroring the recall_events multi-row insert already in the codebase.

Purpose: Auth/ownership work runs once per commit instead of once per card; one INSERT statement instead of N.
Output: A single-insert `saveImageCards`, a single-call `commitReviewRows`, and rewritten tests reflecting all-or-nothing outcome semantics.
</objective>
