SRS rules (src/lib/study-engine.ts — VERIFIED):
  masteryRound: 0=new, 1=round1done, 2=round2done, 3=learned
  ROUND_REQUIREMENT: { 0:"n2t", 1:"t2n", 2:"either" } — advancement needs ONE correct in the required direction; capped +1 round/session.
  Wrong answers do not penalize — the round simply holds (no advance) until a correct in the required direction.
  /api/debug/state cards[i].direction = masteryRoundToDirection(round): round0→"n2t", round1→"t2n", round2+→"either" — this IS the QAJ-01/02 direction assertion target.

Cooldowns (src/app/api/study/complete buildCooldownConfig):
  Local dev default (STUDY_COOLDOWN_MINUTES unset) → 0ms for all rounds (cooldownUntil null) — QAJ-02 wants this for speed.
  STUDY_COOLDOWN_MINUTES=1 → all rounds get a 1-minute cooldown — QAJ-01 REQUIRES this to assert a non-null cooldownUntil.

Habitat level (src/lib/habitat-engine.ts — VERIFIED):
  LEVEL_THRESHOLDS = [5, 15, 30, 50, 80, 120, 170, 230] — level 2 needs effectiveCardCount>=5; level 3 needs >=15 (the "representative higher transition").
  effectiveCardCount = Math.floor(quality * learnedCardCount). For QAJ-04 keep quality=1.0 (study within the 2-day grace, no time-shift) so effectiveCardCount == learnedCardCount.
  gradeSession's response leveledUp === 2 on the session that crosses the L1→2 threshold.
