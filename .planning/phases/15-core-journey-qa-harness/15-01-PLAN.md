<objective>
Build the QA-gated instant time-shift server affordance that the resumable (QAJ-03) and decay/pause (QAJ-05) journeys depend on. A new `POST /api/debug/time-shift` endpoint persists a signed `leo-qa-time-offset` cookie; three pipeline read-points consult it so all SRS/habitat computation honors a simulated `now`. No DB schema change — the shift is purely computational because the SRS and habitat engine functions already accept an explicit `now` parameter.

Purpose: Eliminate real multi-hour/multi-day waits (D-03) while keeping the affordance prod-absent and unreachable when `DEBUG_CHEAT_SECRET` is unset (D-05), mirroring the Phase 14 debug-cheat discipline exactly.
Output: time-shift route + `debug-cheat.ts` helpers + Vitest gate-order test + three threaded callsites + one prod-parity e2e assertion.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| harness/browser → POST /api/debug/time-shift | untrusted client supplies `offsetMs` + `secret` |
| signed cookie → server read-points | `leo-qa-time-offset` value is attacker-influenceable storage |
| QA affordance → production | the endpoint must not exist in prod (secret unset) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Spoofing | leo-qa-time-offset cookie | mitigate | Sign with HMAC-SHA256 over `DEBUG_CHEAT_SECRET` via the existing `hmac`/`base64url` helpers; `verifyTimeOffset` uses `timingSafeEqual` and returns null on mismatch (mirrors `verifyQaMode`) |
| T-15-02 | Elevation of Privilege | time-shift reachable in prod | mitigate | `cheatEnabled()` guard returns 404 BEFORE auth when `DEBUG_CHEAT_SECRET` unset; `readQaTimeOffset()` returns 0 (real `new Date()` unchanged) in that case — provable via the extended QAOB-04 e2e |
| T-15-03 | Tampering | oversized `offsetMs` overflow | mitigate | zod `z.number().int().min(0).max(30*24*60*60*1000)` (≤30 days) on the route body |
| T-15-04 | Information Disclosure | secret echoed/logged | mitigate | Never log `secret` or cookie value; route returns only `{ok:true}` / `{ok:true,cleared:true}` |
| T-15-05 | Repudiation | unauthenticated shift | mitigate | `auth.api.getSession` required (401 without a session) before any cookie write |
| T-15-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages this plan (RESEARCH: zero new deps) — no install task; slopcheck N/A |
