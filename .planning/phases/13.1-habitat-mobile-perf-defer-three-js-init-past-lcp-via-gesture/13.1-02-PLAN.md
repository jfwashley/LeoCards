    New shell behavior:

    1. **State:** `const [canvasMounted, setCanvasMounted] = useState(false)`.
    2. **Reduced-motion gate (R4):** if `usePrefersReducedMotion()` returns true,
       `canvasMounted` is forced false forever AND no gesture listeners are
       attached. The poster IS the experience.
    3. **Poster (R2):** always render `<Image src={`/habitat/hero-l${sceneLevel}.webp`}
       alt={`Tiger habitat level ${sceneLevel}`} fill priority sizes="(max-width:
       768px) 100vw, 720px" style={{ objectFit: "cover", transition: "opacity
       200ms ease-out", opacity: canvasMounted ? 0 : 1 }} />`. DO NOT pass
       `preload` — it is invalid in next/image (Next.js 16). Consult
       `node_modules/next/dist/docs/` for next/image before finalizing prop
       names per AGENTS.md.
    4. **Gesture gate (R3):** in `useEffect` (only runs when !reducedMotion AND
       !canvasMounted), attach passive listeners for `pointerdown`,
       `touchstart`, `keydown`, `wheel`, `scroll` on `document` (and `scroll`
       on `window` — `scroll` does not bubble from window to document in all
       browsers). On any first event, call `setCanvasMounted(true)` and
       detach ALL listeners synchronously. NO `requestIdleCallback`. NO
       `setTimeout` fallback. Cleanup function detaches listeners on unmount.
    5. **Canvas mount (R3):** when `canvasMounted === true`, render the
       `<canvas data-testid="habitat-3d-canvas">` AND run the existing
       `mountHabitatScene` effect. The factory call is UNCHANGED — same args,
       same teardown.
    6. **Wrapper sizing (R6):** wrapper keeps `style={{ aspectRatio: "16/9",
       maxHeight: "min(70vh, 400px)", position: "relative" }}` so it has
       intrinsic size BEFORE either child paints. Poster and canvas are both
       positioned `absolute inset-0` inside, so swap is zero-CLS.
    7. **Dev affordances:** the existing `window.__habitatSetTheta` /
       `window.__habitatCameraPos` blocks inside `mountHabitatScene` are
       unchanged. They only exist post-mount; that's fine — the Plan 01
       Playwright spec triggers a gesture before relying on them (or, simpler,
       loads the page with a synthetic `pointerdown` dispatched in
       `page.evaluate` to force the canvas in for screenshot purposes).
    8. **NO regressions:** `mountHabitatScene` body is unchanged; keyboard
       orbit nudge, scroll-zoom cancel, context-loss handler, RAF loop,
       dispose path — all identical.
