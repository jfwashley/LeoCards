# Phase 13.1 — Habitat Video Migration: CWV Results

**Date:** 2026-05-28
**Strategy:** Replace the live Three.js `/habitat` scene with pre-rendered per-level×mood ambient video clips. Three.js becomes build-time-only (renders the clips in CI; never ships to the client). Decay/quality applied as a live CSS filter; reduced-motion shows the still poster.
**Tool:** Lighthouse 13.3.0, real Chrome, no in-page instrumentation. 3+ runs/cell vs Vercel preview, auth cookie + `x-vercel-protection-bypass` header. Mobile = `--form-factor=mobile --throttling-method=simulate` (Moto G4, Slow 4G, 4× CPU). Desktop = `--preset=desktop`.

## What fixed what
1. **Three.js → video** removed the 504 KB WebGL chunk from the client bundle entirely (`grep WebGLRenderer .next/static/chunks` → none). Killed the parse/exec cost and the on-device rendering bug.
2. **Dropped `motion/react` from habitat-scene** (two fades → CSS `tw-animate-css`). That single 71 KB chunk was ~1512 ms of script-eval under 4× CPU throttle — the entire original TBT. `/habitat` page_client-reference-manifest now has 0 references to the motion chunk. TBT 1049 → 415.
3. **Preloaded priority poster** (`next/image priority` bottom layer + clip `preload="metadata"`). The old `<video poster>` got no preload link → Lighthouse "LCP element: none" → LCP gated behind hydration (~3 s). The webp now paints from a `<link rel=preload>`. LCP 2729 → 1860.

## Residual: TBT 377 ms (mobile)
After removing both Three.js and motion, the remaining main-thread cost is **framework/app-shell baseline** — React hydration + Next runtime + better-auth client + the protected layout. It is NOT habitat-specific (the shared `0v-…` vendor chunk is ~576 ms; `/dashboard` carries the same class of cost at TBT ~286). Getting under the 200 ms gate requires app-wide work: code-splitting/deferring the auth client + providers, trimming the shared vendor chunk, reducing hydration. That is precisely **Phase 999.1 (perf initiative)** scope and should be done there against a whole-app baseline, not bolted onto /habitat.

**Decision:** Ship. /habitat mobile passes LCP + CLS, scores Perf 90 (green band), and renders reliably with the designer's 3D art alive (ambient loop) — a viable customer-facing product. The residual TBT is carried to Phase 999.1.
