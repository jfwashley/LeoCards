<objective>
Generate the nine full-resolution `/habitat` poster webps that Plan 02 will use
as the LCP element. The poster generation is a build-time, one-shot pipeline —
not part of `npm run build`. It exists so any future scene change can be
re-baked with one command.

Purpose: R1 — the LCP image must be a real, full-viewport hero (20–100 KB,
≥ 720×405) so Chrome treats it as the LCP candidate. Attempt #1 reused
80 px widget posters and Chrome refused to nominate them.

Output:
- Playwright spec that loops levels 1..9 at viewport 1280×720, sets a fixed
  orbit theta via `window.__habitatSetTheta`, waits for `data-ready=true`,
  and screenshots the canvas to a PNG.
- A small node orchestrator that drives the Playwright run, converts PNG →
  webp via `sharp`, and validates each output is 20–100 KB and ≥ 720×405.
- The nine webps committed to `public/habitat/hero-l{1..9}.webp`.
- A `posters:habitat` npm script.
</objective>
