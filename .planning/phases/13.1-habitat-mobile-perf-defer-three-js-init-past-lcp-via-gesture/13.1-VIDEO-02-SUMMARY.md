# Phase 13.1 Plan VIDEO-02: Habitat Client Swap (Live Canvas → Baked Video) Summary

Swapped the user-facing `/habitat` scene from the live Three.js canvas to the
pre-rendered ambient loop clips baked in Plan VIDEO-01. After this change,
**no client code imports `habitat-3d-canvas.tsx` or `src/lib/habitat-3d/*`**,
so three.js leaves the client bundle entirely.

## Component design — `HabitatVideo`

A `"use client"` component, `{ habitatState }` in. Pure exported helpers
(`clampLevel`, `clipBasename`, `posterSrc`, `webmSrc`, `mp4Src`, `decayFilter`)
make selection logic node-env testable (repo Vitest has no jsdom).

- **Clip selection:** level clamped to `[1,9]`, basename `l${level}-${mood}`.
- **Normal path:** `<video autoPlay muted loop playsInline preload="auto"
  poster="/habitat/hero-l{N}.webp">` with two `<source>` — webm first
  (`video/webm`), mp4 fallback (`video/mp4`). `position:absolute; inset:0;
  objectFit:cover` fills the parent wrapper. `key={basename}` forces a clean
  reload when level/mood changes. The poster webp is the instant LCP candidate.
- **CLS=0:** the wrapper in `habitat-scene.tsx` carries the intrinsic 16/9
  size; video/still are absolutely positioned inside, so nothing reflows.

## Decay-filter curve

`decayFilter(quality)` maps the engine's quality (0.1–1.0) to a CSS `filter`:

| quality | filter |
|---|---|
| 1.0 | `none` |
| 0.7 | `saturate(0.700) brightness(0.880)` |
| 0.4 | `saturate(0.400) brightness(0.760)` |
| 0.1 (floor) | `saturate(0.100) brightness(0.640)` |

Formula: `saturate(q) brightness(0.6 + 0.4·q)`, `q` clamped to `[0.1, 1]` to
match `DECAY_FLOOR`. A neglected habitat reads washed-out and cold without
becoming unreadable. **Filter-only → zero layout impact.** Applied to BOTH the
video and the reduced-motion still.

## Reduced-motion handling

SSR-safe: `usePrefersReducedMotion` defaults `false` on the server and the first
client render, so the server always emits the `<video>` markup (deterministic,
no CLS). After mount, if `(prefers-reduced-motion: reduce)` matches, the
component swaps to a static poster still (`next/image` `unoptimized priority
fill`, `data-testid="habitat-video-still"`) — **no autoplaying motion** for
reduced-motion users. The decay filter still applies to the still.
