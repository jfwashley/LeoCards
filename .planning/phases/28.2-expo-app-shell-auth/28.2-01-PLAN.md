Raise `better-auth` from the installed 1.5.6 to the version `@better-auth/expo` requires as a hard
peer floor, install `@better-auth/expo` itself, and prove the existing web app is completely
unaffected — all before a single line of native code is written.

isolated, regression-tested and human-approved on its own, separately from the `src/lib/auth.ts`
plugin edit that follows in plan 28.2-03.

source-code changes. **This plan changes no `src/` file and pushes nothing.**
