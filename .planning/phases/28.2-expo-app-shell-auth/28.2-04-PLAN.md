  workspace lockfile grows what Vercel installs on every deploy. Keeping it behind the deploy means

  used in production today. RESEARCH's install list omits them, but the native auth forms need all
  three (28.2-PATTERNS Group B). Declaring them explicitly rather than relying on workspace hoisting
  is the correct workspace hygiene; they need no legitimacy gate.
- **Full `zod`, not `zod/mini`, on native** — resolving RESEARCH Open Question 1 in the direction it
  recommends. `zod/mini` exists on web purely to cut client-bundle size for the Lighthouse/CWV gates
  (PERF-14); there is no Lighthouse score on React Native, so the constraint does not transfer and
  full `zod`'s chaining API is simpler for form schemas.
- **The Expo Go probe uses the EXISTING 28.1 placeholder entry.** It is a pure tooling probe: does
  Metro serve, does the phone connect over LAN, does the emulator launch. Zero new code means a
  failure here can only be an environment problem, never a code problem.
</planner_decisions>
