<objective>
Create the pure, importable computation core of the CWV measurement harness — median statistics, bundle-stats parsing, the D-07 bottleneck classifier, and the D-04 markdown/summary renderers — plus the Wave-0 unit tests and fixture that lock their behavior.

This is the CONTRACT layer. Plan 02's side-effectful harness (`scripts/measure-cwv.mjs`) imports every function defined here rather than reimplementing them. Splitting the pure logic into `scripts/measure-cwv-lib.mjs` is mandatory because the full harness has a top-level `DATABASE_URL` guard + `await puppeteer.launch(...)` that would crash `npx vitest run` (which collects `scripts/**/*.test.ts` — only `e2e/**` is excluded). The lib has NO env guard and NO top-level await, so it imports cleanly in a test.

Purpose: Make the harness's decision logic (which number is the baseline, which bottleneck is the top Phase-17 target) unit-verified and diff-safe before any network code exists.
Output: `scripts/measure-cwv-lib.mjs` + `scripts/__tests__/measure-cwv-lib.test.ts` + `scripts/__tests__/fixtures/route-bundle-stats.fixture.json`.
</objective>
