|----------|-------------|
| browser cookie → server session | The signed cookieCache payload now carries session state client-side for up to 5 min |
| revocation event → other devices | change-password `revokeOtherSessions` / delete-account invalidate server-side; cached-cookie devices lag |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-01-01 | Elevation of Privilege | session.cookieCache (5-min stale window) | accept | D-03 accepted trade-off: bounded 5-min TTL; a deleted user's writes still fail at the DB layer (FK cascades removed rows). Do not widen TTL. |
| T-27-01-02 | Information Disclosure | /account + 2 mutation server actions | mitigate | D-04: getSessionFresh (disableCookieCache) forces a live DB read on the 3 revocation-sensitive paths; verified by the account e2e/unit suite |
| T-27-01-03 | Tampering | cookieCache payload integrity | accept | better-auth default "compact" strategy is HMAC-SHA256-signed (first-party, not hand-rolled); no encryption needed for non-sensitive id/email/expiry payload |
| T-27-01-SC | Tampering | npm/pip/cargo installs | n/a | No package installs this phase (RESEARCH confirms zero new deps) |
