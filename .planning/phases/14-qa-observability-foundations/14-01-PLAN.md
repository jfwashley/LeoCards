<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser cookie -> RSC/route handler | The `leo-qa-mode` cookie is attacker-controllable; every read must HMAC-verify server-side |
| client request -> /api/debug/* | Untrusted callers may probe QA endpoints with guessed secrets / forged cookies |
| env (Vercel scope) -> server | STUDY_COOLDOWN_MINUTES controls real spaced-repetition timing |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Spoofing/Tampering | `leo-qa-mode` cookie forgery | mitigate | HMAC-SHA256 sign (signQaMode) + constant-time `timingSafeEqual` verify (verifyQaMode); fixed sentinel payload — no user-controlled fields to inject |
| T-14-02 | Information Disclosure | DEBUG_CHEAT_SECRET / env leaking to client | mitigate | debug-cheat.ts and env server block stay server-only (no `"use client"`); QA cookie is httpOnly so client JS cannot read it |
| T-14-03 | Elevation of Privilege | QA endpoints reachable without secret | mitigate | `cheatEnabled()` 404 guard preserved on cheat + state routes; `checkSecret()` constant-time gate retained; QAOB-04 (Plan 03) proves 404 when unset |
| T-14-04 | Tampering | Negative/zero/NaN cooldown via STUDY_COOLDOWN_MINUTES | mitigate | t3-env `z.number().int().min(1)` rejects 0/negatives; transform/pipe coercion prevents NaN (RESEARCH pitfall 3) |
| T-14-05 | Tampering | STUDY_COOLDOWN_MINUTES set in production shortens real SRS | accept | D-10: no code-level prod block by design; control is Vercel env scoping (Preview only). QAOB-04 proves unset => real 12h/24h defaults |
| T-14-06 | Information Disclosure | /api/debug/state cards[] leaks another user's SRS data | mitigate | cards query scoped to `session.user.id`; session required (401) before secret gate (403); 200-row cap bounds payload |
| T-14-SC | Tampering | npm/pip/cargo installs | mitigate | Zero new packages this phase (RESEARCH: "installs zero new packages") — no install task, no legitimacy gate needed |
</threat_model>
