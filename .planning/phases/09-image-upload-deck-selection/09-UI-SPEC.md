## Spacing Scale

All values are Tailwind utility classes mapped to the 4-point base. The existing codebase uses Tailwind spacing directly — no custom spacing tokens defined beyond what Tailwind provides.

| Token | Value | Tailwind Class | Usage in This Phase |
|-------|-------|----------------|---------------------|
| xs | 4px | `gap-1` / `p-1` | Icon gaps inside buttons, inline SVG padding |
| sm | 8px | `gap-2` / `p-2` | Space between label and input, between inline controls |
| md | 16px | `gap-4` / `p-4` | Card content padding (matches `CardContent px-4`), element spacing within steps |
| lg | 24px | `gap-6` / `p-6` | Vertical separation between the mode toggle and the step body |
| xl | 32px | `gap-8` / `px-8` | Page outer padding (matches existing `main px-8 py-8`) |
| 2xl | 48px | — | Not used in this phase |
| 3xl | 64px | — | Not used in this phase |

**Exceptions:**
- Touch targets: interactive elements without explicit size (create-deck language buttons) must have `min-h-[44px]` — matches existing `deck-switcher.tsx` pattern.
- Drop zone: minimum height 128px (`min-h-32`) to provide an adequate drag-and-drop surface.
- Preview thumbnail: max height 256px (`max-h-64`) — locked by CONTEXT.md D-05.

**Source:** `src/components/deck-switcher.tsx` (min-h-[44px] pattern), `new-card/page.tsx` (px-8 py-8 page padding), `src/components/ui/card.tsx` (px-4 card content)

## Color

All color values are CSS custom properties defined in `src/app/globals.css`. The theme is warm orange/amber (LeoCards brand).

| Role | CSS Variable | Light Mode HSL | Usage |
|------|-------------|----------------|-------|
| Dominant (60%) | `--background` | `hsl(30 20% 98%)` — near-white warm | Page surface, drop zone idle background |
| Secondary (30%) | `--card` / `--muted` | `hsl(30 15% 96%)` card, `hsl(30 10% 92%)` muted | Card wrapper (image flow lives in a Card), drag-over highlight fills, preview container background |
| Accent (10%) | `--primary` | `hsl(24 95% 53%)` — warm orange | Reserved for: active mode toggle button, the "Extract words" primary CTA, the focus ring (`--ring` matches `--primary`) |
| Destructive | `--destructive` | `hsl(0 84% 60%)` — red | Inline validation error text (`text-destructive`) for wrong file type and oversized file errors |
| Border | `--border` | `hsl(30 10% 88%)` | Drop zone idle border, card ring, input borders |
| Muted foreground | `--muted-foreground` | `hsl(0 0% 45%)` — medium gray | Helper text, drag-and-drop instruction copy, inactive mode toggle label |
| Foreground | `--foreground` | `hsl(0 0% 9%)` — near-black | Body text, primary labels |

**Accent reserved for (explicit list):**
1. Active/selected mode toggle button (the currently active mode uses `variant="default"` = primary fill)
2. The "Extract words" primary CTA button
3. Focus ring on all interactive elements (already global via `--ring`)

**Accent NOT applied to:** the drop zone border idle state, "Choose different image" button (uses `variant="outline"`), "Back" navigation link (uses `text-muted-foreground hover:underline`), Step progression "Next" button — the Step 1 → Step 2 advance button uses `variant="default"` (primary) as it is the primary action for that step.

**Drag-over state color:** `bg-muted` (secondary fill) with `border-primary` (accent border) — communicates valid drop target without overwhelming the accent allocation.

**Source:** `src/app/globals.css` (full token definitions)

## Interaction States

### Mode Toggle

Two buttons side by side: "Type a word" | "From image"

| State | Visual |
|-------|--------|
| Active mode | `Button variant="default"` (primary orange fill, white text) |
| Inactive mode | `Button variant="outline"` (transparent bg, border, foreground text) |
| Hover (inactive) | `hover:bg-muted` (built into outline variant) |
| No disabled state | Both modes always clickable; switching modes does not lose image state if returning |

**Rationale for button pair over tabs:** No native shadcn/Radix Tab component is in the existing `src/components/ui/` directory. The button pair reuses the one primitive already present, at zero cost. (Source: CONTEXT.md Claude's Discretion, RESEARCH.md Open Question 1)

### Drop Zone — Step 1

| State | Visual Treatment |
|-------|-----------------|
| Idle (empty) | `border-2 border-dashed border-border` on a `rounded-xl` container; `bg-background`; Upload icon (muted-foreground) + helper text centered |
| Drag over | `border-primary` (accent orange) + `bg-muted` fill; text changes to "Drop it here" |
| Error (invalid file) | Border stays `border-border`; inline error paragraph appears below zone: `text-sm text-destructive` |
| Previewing (valid file) | Drop zone replaced by preview block: `<img>` with `max-h-64 w-auto object-contain rounded-lg`; X button overlay (top-right); "Choose different image" button below |

### Preview — Step 1 previewing state

| Element | Spec |
|---------|------|
| Thumbnail container | `relative` positioned wrapper; `max-h-64` constraint; `w-auto`; `object-contain` |
| Preview image | Plain `<img>` (not `next/image`); `rounded-lg`; `max-h-64 w-auto object-contain` |
| X clear button | `Button variant="ghost" size="icon"` positioned `absolute top-2 right-2`; `aria-label="Remove selected image"` |
| "Choose different image" | `Button variant="outline"` below thumbnail; re-triggers `inputRef.current.click()` |
| Advance to Step 2 | `Button variant="default" className="w-full"` — "Next: choose deck" — enabled when `state.file !== null` |

### Step 2 — Deck confirmation

| Element | Spec |
|---------|------|
| Recap thumbnail | Same `<img>` render at reduced size — `max-h-32 w-auto object-contain rounded-md` — "here's what you picked" |
| Deck label | `Label` "Add words to:" |
| DeckSwitcher | Renders exactly as-is per D-10; receives `state.selectedDeckId` + `dispatch SET_DECK` |
| Back navigation | `Button variant="ghost"` with `ArrowLeft` icon (16px) + "Back" text; dispatches `BACK_TO_PICK`; returns to previewing state with file still held |
| Extract CTA | `Button variant="default" className="w-full h-11"` — "Extract words"; `disabled` until `state.file !== null && state.selectedDeckId` (both required); no-op handler in Phase 9 |

## Validation Error Patterns

Match `TranslationForm`'s established inline error pattern exactly:

```tsx
{state.pickError && (
  <p className="text-sm text-destructive mt-2">{state.pickError}</p>
)}
```

- Position: immediately below the drop zone
- No toast, no banner, no dialog — inline only (D-08)
- Error clears on next valid file selection (new `FILE_PICKED` dispatch sets `pickError: null`)
- Error persists if user drag-hovers over zone again without picking a new file

## Accessibility Contract

| Requirement | Implementation |
|-------------|---------------|
| Keyboard operability | Drop zone has `role="button" tabIndex={0} onKeyDown` — Enter/Space opens file picker |
| File input label | `<input type="file" className="sr-only" aria-label="Upload image">` |
| Drop zone ARIA | `aria-label="Select image file — click, drag and drop, or paste from clipboard"` |
| Clear button ARIA | `aria-label="Remove selected image"` |
| Error announcement | Inline `<p>` is in natural reading order — screen reader reads on next focus/navigation; no `aria-live` required for this low-frequency interaction |
| Focus management | No programmatic focus moves between steps — user navigates naturally via Tab; this is appropriate for an in-page flow, not a modal |
| Drag-and-drop fallback | Click-to-browse and paste are always available; drag is progressive enhancement |
| Colour contrast | `text-destructive` (`hsl(0 84% 60%)`) on `bg-background` (`hsl(30 20% 98%)`) — passes WCAG AA (4.5:1 minimum); verified by token proximity |
| Disabled Extract button | `disabled` attribute + `disabled:opacity-50` (built into buttonVariants) — communicates not-ready state without hiding the affordance |

## Design Decisions Log

Decisions made during this UI-SPEC (auto mode — derived from upstream artifacts):

| Decision | Choice | Source |
|----------|--------|--------|
| Mode toggle shape | Two-button pair (default/outline) | CONTEXT.md Claude's Discretion → RESEARCH.md Open Q1 → existing Button primitive only |
| Back navigation style | Ghost Button with ArrowLeft icon (no confirmation) | Matches TranslationForm back link pattern; file is not lost on back |
| Drop zone dashed border | `border-2 border-dashed border-border` | Standard drop zone convention; no existing precedent to deviate from |
| Drag-over highlight | `border-primary bg-muted` | Accent border signals valid target; muted fill avoids full accent saturation |
| Step 2 recap thumbnail size | `max-h-32` (half of Step 1 max-h-64) | Communicates "this is a recap, not the primary focus" without hiding the choice |
| No destructive confirmation for clear | Immediate clear | File not uploaded; action reversible; low stakes |
| Extract button height | `h-11` (matches TranslationForm Save button explicit height) | Visual consistency with the form it sits beside |
