## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, badge internal padding, source indicator pill padding |
| sm | 8px | Card list row vertical padding, button icon gap, search bar internal padding (vertical) |
| md | 16px | Default element spacing, form field gap, card list column gap |
| lg | 24px | Card and panel internal padding, section gap in word list browser |
| xl | 32px | Page content max-width horizontal padding, gap between header and page body |
| 2xl | 48px | Vertical gap between page heading and content area |
| 3xl | 64px | Reserved — not used in Phase 2 |

Exceptions:
- Touch targets (card row actions, +/- toggle buttons, header deck switcher) minimum 44px height — WCAG 2.5.5
- Word list +/- toggle button: 44px × 44px minimum tap area; visual size may be smaller with padding compensation
- Card list row height minimum 48px to ensure comfortable tap on touch devices
- Header height: 56px fixed (accommodates deck switcher + logout at comfortable touch scale)

## Color

Inherited from Phase 1 — tokens confirmed in `src/app/globals.css`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(30 20% 98%)` — warm white | Page background, header background, modal overlay backdrop base |
| Secondary (30%) | `hsl(30 15% 96%)` — warm card | Card list row background (alternating or hover), word list category panel, edit modal background |
| Accent (10%) | `hsl(24 95% 53%)` — orange | Primary CTA buttons only (see reserved list below) |
| Destructive | `hsl(0 84% 60%)` — red | Delete card button in edit modal, delete confirmation CTA, inline translation error text |

Accent (`--primary`) reserved for:
1. "Save card" button on manual card entry page (primary CTA for that view)
2. "Create deck" button on first-visit language picker (primary CTA for that flow)
3. Focus ring on all interactive form elements (`ring-primary` / `--ring`)
4. Active/checked state of word list +/- toggle when a word is added to the deck (checkmark icon rendered in accent color)

Accent is NOT used for: heading text, body copy, card list row hover state, CEFR badges, source indicator pills, navigation links, the deck switcher trigger, or the search input.

Secondary action style for non-primary buttons:
- "Cancel" in modals: `variant="outline"` — border-border, no fill
- "Edit" row icon button: `variant="ghost"` — no border, hover shows muted background
- Search clear button: `variant="ghost"`
- Word list "−" remove button: `variant="ghost"` with destructive-colored icon (not full destructive style — icon only)

CEFR badge colors (within the warm palette):
- A1: `bg-muted text-muted-foreground` — lowest visibility, beginner
- A2: `bg-secondary text-secondary-foreground` — same muted family
- B1: `bg-secondary text-foreground font-medium` — slightly stronger, intermediate

Source indicator pill:
- "word list": `bg-muted text-muted-foreground text-xs`
- "manual": `bg-muted text-muted-foreground text-xs`
(No color distinction between sources — both use muted; the label text is the differentiator.)

## Pages and States in Scope

Phase 2 delivers: a rebuilt `/dashboard` (deck management view), a `/deck/new-card` page (manual card entry), and a first-visit language picker flow. Each state is defined below.

### /dashboard (Deck Management View — replaces Phase 1 stub)

#### Sub-state: First visit — no decks exist

| State | Behavior |
|-------|----------|
| Default | Full-page centered card with heading "What language do you want to learn?" and three language buttons (English / French / Spanish, each with flag emoji). The user's native language is excluded. |
| Loading | Language button shows spinner + disabled after click; other buttons also disabled |
| Error | Inline error below buttons: "Something went wrong. Try again." — not a toast |

#### Sub-state: Deck exists — card list view

| State | Behavior |
|-------|----------|
| Default | Header with deck switcher + logout; search bar; "Browse words" and "Add a card" action buttons; card list table |
| Empty deck | Card list area replaced by empty state (see Copywriting below) — action buttons remain visible |
| Search active | Card list filters live to contains-match; no results state (see Copywriting); clear icon appears in search field |
| Loading (page) | Card rows replaced by skeleton rows (3×) using `bg-muted animate-pulse`; header and actions remain visible |
| Error (load failed) | Card list area replaced by error state (see Copywriting below) |

#### Card list row states

| State | Behavior |
|-------|----------|
| Default | Native word | Target translation | Source pill | Edit icon button |
| Hover | Row background shifts to `bg-secondary` (warm card); edit icon becomes fully visible (vs 60% opacity at rest) |
| Edit icon click | Opens card-edit-dialog |

### /deck/new-card (Manual Card Entry)

| State | Behavior |
|-------|----------|
| Default | Two side-by-side inputs (native language label + target language label), "Save card" CTA (disabled until both fields have content), back navigation link |
| Typing — translation pending | The non-active field shows a skeleton shimmer (`bg-muted animate-pulse`) while debounce fires and request is in flight |
| Translation resolved | Non-active field populates with translated text; user can edit it freely |
| Translation error | Non-active field clears; inline error appears below the field: "Translation unavailable. Enter manually." |
| Save success | Both fields clear; inline success message appears below the form: "Card saved." — auto-dismisses after 3 seconds |
| Save loading | "Save card" button disabled + spinner; fields remain editable |
| Save error | Inline error below the form: "Couldn't save card. Try again." |
| Empty native field | "Save card" button remains disabled; no error shown until save is attempted |

### Word List Browser (accessible from /dashboard via "Browse words" button)

The word list browser is either a full-page route (`/deck/browse`) or a slide-in panel. Based on CONTEXT.md ("no search bar — browse only"), a dedicated page is cleaner than a panel.

Route: `/deck/browse`

| State | Behavior |
|-------|----------|
| Default | Category tabs/pills at top (14 categories), difficulty filter (All / A1 / A2 / B1), word rows below |
| Category selected | Word rows filtered to selected category; scroll to top of list |
| Difficulty filtered | Word rows filtered to selected CEFR level within active category |
| Word not in deck | Row shows: native word | target translation | "+" button (accent icon, outlined) |
| Word in deck | Row shows: native word | target translation | checkmark + "−" button (muted icon); row background `bg-secondary` |
| Add loading | "+" button shows spinner, disabled; other rows interactive |
| Remove loading | "−" button shows spinner, disabled; other rows interactive |
| Add/remove error | Inline error icon in the row; tooltip or adjacent text: "Failed. Try again." |

### Card Edit Dialog (modal — triggered from card list)

| State | Behavior |
|-------|----------|
| Default open | Both native and target fields pre-populated with current values; "Save changes" CTA (accent); "Cancel" button (outline); "Delete card" link/button (destructive color, bottom of modal) |
| Saving | "Save changes" disabled + spinner; fields locked |
| Save success | Modal closes; card list row updates inline |
| Save error | Inline error below "Save changes": "Couldn't save. Try again." |
| Delete click | Confirmation dialog opens (nested or replaces content — see below) |

### Delete Confirmation Dialog

| State | Behavior |
|-------|----------|
| Default | Heading "Delete this card?", body "This can't be undone.", "Delete" CTA (destructive), "Cancel" button (outline) |
| Deleting | "Delete" disabled + spinner |
| Delete success | Both dialogs close; card removed from list without page reload |
| Delete error | Error text inside dialog: "Couldn't delete. Try again." — dialog stays open |

### Deck Switcher (header — present on all /dashboard and /deck/* routes)

| State | Behavior |
|-------|----------|
| Default | Shows current deck as flag emoji + auto-name (e.g., "🇫🇷 French #1") |
| Open | Dropdown lists all user decks (flag + name); "+ New deck" at bottom |
| "+ New deck" click | Opens language picker inline or as a popover: languages excluding native language; creates deck and selects it |
| Creating deck | Language option shows spinner; other options disabled |
| Single deck | Switcher still shown (user may add more decks later) |

## Interaction Contracts

### Header Layout

- Fixed top header, `h-14` (56px), `bg-background border-b border-border`
- Left slot: TioCards wordmark (`text-sm font-semibold text-foreground`) + tiger emoji 🐯 (rendered as text, `text-lg`)
- Center/right slot: Deck switcher (shadcn Select, `min-w-[160px]`)
- Far right: Logout button (inherited from Phase 1, `variant="ghost"` text size label)
- No additional nav links in Phase 2

### Deck Switcher (shadcn Select — @base-ui/react/select)

- Trigger: `variant="outline"` appearance — border, no fill, flag emoji + deck name
- Dropdown item format: `{flag} {deck-name}` (e.g., "🇫🇷 French #1")
- Active deck item: checkmark icon on the right side
- Separator before "+ New deck" item
- "+ New deck" item uses lucide `Plus` icon on left, muted text style

### Card List Table

- Layout: full-width, no fixed column widths — native and target columns flex-grow equally; source pill fixed ~80px; action column fixed 44px
- Row border: `border-b border-border`
- Column headers: Label size (14px/400), `text-muted-foreground`, not sortable in Phase 2
- Search bar: full width above table, shadcn `<Input>` with lucide `Search` icon as left adornment, lucide `X` clear button on right (visible only when query is non-empty)
- Search behavior: client-side contains-match on both native and target fields; no debounce needed (local filtering)
- Action buttons above table (right-aligned): "Browse words" (`variant="outline"`) and "Add a card" (`variant="outline"`) — both equal weight; neither is accent-colored

### Word List Browser

- Category navigation: horizontal scrollable pill row at top; active pill uses `bg-primary text-primary-foreground`; inactive uses `bg-muted text-muted-foreground`
- Difficulty filter: segmented control or three pills (All | A1 | A2 | B1); same pill style as categories but below the category row
- Word rows: same border-bottom row style as card list; no checkboxes — action is the +/- button only
- +/- button: 44px tap area, `variant="ghost"`, icon changes between lucide `Plus` (not in deck) and lucide `CheckCheck` (in deck); color changes to accent when in deck
- Back navigation: link in the header area or breadcrumb: "← My deck" using `text-sm text-muted-foreground hover:underline`

### Manual Card Entry Form

- Layout: Two-column grid (`grid grid-cols-2 gap-4`) for the translation inputs
- Each column has a `<Label>` above the `<Input>` — native language label on left, target language label on right (e.g., "English" | "French")
- Translation-in-progress: skeleton shimmer on the receiving input — `bg-muted animate-pulse rounded-md h-10` — replaces the Input while request is in flight
- "Save card" CTA: full width below the two-column grid; `variant="default"` (accent); `disabled` until both fields non-empty
- Success message: `text-sm text-green-600` inline below the CTA; auto-clears after 3s (use `setTimeout` + state)
- Error messages: `text-sm text-destructive` inline below the relevant field or below CTA for save errors
- Back link: above the form, `text-sm text-muted-foreground hover:underline` with lucide `ArrowLeft` icon: "← Back to my deck"

### Card Edit Dialog

- Modal trigger: lucide `Pencil` icon button (`variant="ghost"`, 44px tap area) in each card list row
- Dialog width: `max-w-md` (448px), centered
- Both fields use shadcn `<Input>` with visible `<Label>` above each
- "Save changes" button: `variant="default"` (accent), full width
- "Cancel" button: `variant="outline"`, full width — stacked below Save, or side by side if space allows
- "Delete card": text link with lucide `Trash2` icon, `text-sm text-destructive`, positioned at bottom of modal with visual separator
- Nested delete confirmation: replaces the edit form content within the same Dialog — do not open a second Dialog on top

### Delete Confirmation (inline within Edit Dialog)

- Replace dialog body content (animate with `opacity` transition, not slide)
- "Delete" CTA: `variant="destructive"`, full width
- "Cancel": `variant="outline"`, full width — returns to edit view (does not close the dialog)

### First-Visit Language Picker

- Full page centered card (same `max-w-sm` width as auth cards, `rounded-xl shadow-sm`, 24px padding)
- Tiger emoji 🐯 above heading (same pattern as auth pages — brand consistency)
- Heading: "What language do you want to learn?" (Heading size, 20px/600)
- Three language buttons stacked vertically: flag emoji + language name, each `variant="outline"`, `h-11`, `w-full`
- Excludes user's native language — only 2 buttons visible for most users
- Auto-creates deck and redirects to `/dashboard` on selection

### Form Inputs (inherited from Phase 1)

- All inputs use shadcn `<Input>` component
- Every field has a visible `<Label>` above it — placeholder text is hint-style, not label replacements
- Error state: `border-destructive` + `text-sm text-destructive` below field
- No red borders until save is attempted; after save attempt, errors appear on blur

### Buttons (inherited from Phase 1)

- Primary CTA: `variant="default"` — `bg-primary text-primary-foreground`
- Loading state: lucide `Loader2` with `animate-spin` replaces button text; `disabled`
- Minimum height: 44px (`h-11`)
- Destructive: `variant="destructive"` — `bg-destructive text-destructive-foreground`
