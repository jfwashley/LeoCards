    2. **Create `src/components/translation-form.tsx`** — client component (`"use client"`):

       Props: `{ deckId: string, nativeLang: string, targetLang: string, nativeLangLabel: string, targetLangLabel: string }`

       **Layout:**
       - Two-column grid: `grid grid-cols-2 gap-4`
       - Left column: `<Label>{nativeLangLabel}</Label>` above `<Input>` for native word
       - Right column: `<Label>{targetLangLabel}</Label>` above `<Input>` for target word
       - Below grid: "Save card" button, full width, `variant="default"` (accent), disabled until both fields non-empty

       **Bidirectional translation (per RESEARCH.md Pattern 2):**
       - Use `useDebounceCallback` from `use-debounce` with 500ms delay
       - Track which field the user last typed in via `useRef<"native" | "target" | null>(null)` — this is `activeField`
       - When user types in native field:
         - Set `activeField.current = "native"`
         - Update nativeText state
         - Trigger debounced translate: `translateFrom(text, "native")`
       - When user types in target field:
         - Set `activeField.current = "target"`
         - Update targetText state
         - Trigger debounced translate: `translateFrom(text, "target")`
       - `translateFrom` function:
         - If text is empty/whitespace, return (don't translate)
         - Set `isTranslating = true` state
         - POST to `/api/translate` with `{ text, sourceLang, targetLang }` mapped correctly based on direction
         - On success: ONLY update the OTHER field if `activeField.current` still matches the triggering field (prevents feedback loop)
         - Set `isTranslating = false`
         - On error: clear the other field, show inline error "Translation unavailable. Enter manually." below the translated field

       **Translation-in-progress state:**
       - The receiving input (NOT the one being typed in) shows a skeleton shimmer: replace `<Input>` with `<div className="bg-muted animate-pulse rounded-md h-10 w-full" />` while `isTranslating` is true AND this field is the receiving one

       **Save flow:**
       - Click "Save card" → set saving state → call `saveCard(deckId, nativeText, targetText, "manual")`
       - Loading: button shows lucide `Loader2` with `animate-spin` + disabled, fields remain visible
       - Success: clear both fields, show inline success message "Card saved." in `text-sm text-green-600` below the button — auto-dismiss after 3 seconds via `setTimeout`
       - Error: show "Couldn't save card. Try again." in `text-sm text-destructive` below button
       - After clearing, user stays on the same page to add more cards

       **Validation:**
       - "Save card" button disabled when: either field is empty, or save is in progress
       - No Zod validation needed client-side — server action validates

       **Imports:**
       - `useDebounceCallback` from `use-debounce`
       - `useState, useRef, useCallback` from `react`

       - `Label` from `@/components/ui/label`
       - `Loader2` from `lucide-react`
       - `saveCard` from `@/lib/deck-actions`
