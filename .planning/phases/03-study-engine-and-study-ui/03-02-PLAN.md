**Zod schema:**
```typescript
const GradeSchema = z.object({
  cardId: z.string(),
  direction: z.enum(["n2t", "t2n"]),
  correct: z.boolean(),
});

const CommitSchema = z.object({
  deckId: z.string(),
  grades: z.array(GradeSchema).min(1).max(500),
});
```

**POST handler flow:**

1. Auth check: `auth.api.getSession({ headers: await headers() })` — return 401 if null.

2. Parse body with try/catch, validate with CommitSchema.safeParse — return 400 if invalid.

3. Verify deck ownership: query `decks` where `id = deckId AND userId = session.user.id`. If no row found, return 403 `{ error: "Forbidden" }`.

4. Load current card states: query `cards` where `id IN (all unique cardIds from grades) AND deckId = parsed.data.deckId`. Store as a Map<string, { masteryRound: number }>. If any cardId is not found in the deck, return 400 `{ error: "Invalid card" }`.

5. Group grades by cardId. For each card, call `computeCardUpdate(cardId as CardId, card.masteryRound, cardGrades, now)` to get `{ newRound, cooldownUntil, recallCountDelta }`.

6. Execute a single `db.transaction(async (tx) => { ... })` containing:

   a. Insert all recall_events in one batch:
   ```typescript
   await tx.insert(recall_events).values(
     parsed.data.grades.map(g => ({
       id: crypto.randomUUID() as RecallEventId,
       cardId: g.cardId as CardId,
       direction: g.direction,
       correct: g.correct,
     }))
   );
   ```

   b. Update each card individually in the transaction loop:
   ```typescript
   for (const update of cardUpdates) {
     await tx.update(cards)
       .set({
         masteryRound: update.newRound,
         cooldownUntil: update.cooldownUntil,
         recallCount: sql`"recallCount" + ${update.recallCountDelta}`,
         lastStudiedAt: now,
       })
       .where(eq(cards.id, update.cardId as CardId));
   }
   ```

   c. Upsert habitat_metadata (Pitfall 5 — row may not exist):
   ```typescript
   await tx.insert(habitat_metadata)
     .values({
       id: crypto.randomUUID(),
       userId: session.user.id,
       lastActivityAt: now,
     })
     .onConflictDoUpdate({
       target: habitat_metadata.userId,
       set: { lastActivityAt: now },
     });
   ```

   Import `sql` from "drizzle-orm" for the recallCount increment.

7. Return `Response.json({ success: true })` with status 200.

8. Wrap the entire transaction block in try/catch. On error, return 500 `{ error: "Failed to save session" }`.

**Critical correctness notes:**
- The `sql` template for recallCount uses double-quoted column name `"recallCount"` because Drizzle generates quoted identifiers.
- Use `crypto.randomUUID()` for recall_event IDs (same pattern as deck-actions.ts).
- Cast `g.cardId as CardId` at the boundary (established Phase 2 pattern for branded types).
- The `now` variable is `new Date()` created once at the top of the handler, shared across all computations for consistency.
