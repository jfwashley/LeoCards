## Interaction Contracts

### LevelUpOverlay

**Trigger:** Study session commits successfully (`COMMIT_DONE` action dispatched) AND `leveledUp` field in API response is non-null.

**Enter animation:** `motion.div` — `opacity: 0 → 1`, duration 300ms, ease default.

**Exit animation:** `motion.div` — `opacity: 1 → 0`, duration 200ms. Requires `AnimatePresence` wrapper in parent.

**Dismiss:** Click/tap anywhere on the overlay calls `onDismiss`. No secondary confirm. No close button required — "tap anywhere" is the affordance.

**Confetti:** 36 `motion.div` pieces. Distributed across full viewport width (`5vw` to `95vw`). Fall from `-10vh` to `110vh`. Duration: 2.5s. Stagger delay: `(index % 8) * 0.07s`. Ease: `easeIn`. Pointer-events: none (decorative only).

**Overlay content layout (top-to-bottom):**
1. Confetti layer — `absolute`, full screen, `pointer-events-none`
2. Level label — `text-sm` 400 weight, `text-muted-foreground` — e.g., "Habitat Level"
3. Level number — `text-[28px]` 600 weight, `text-primary` — e.g., "5"
4. Unlock message — `text-base` 400 weight, `text-foreground` — e.g., "Your habitat grew!" (level 2–9) or "A bird arrived!" (level 10)
5. Dismiss hint — `text-sm` 400 weight, `text-muted-foreground` — "Tap anywhere to continue"

**Exactly-once guarantee:** Overlay only shows when the API returns `leveledUp: N`. The API only returns non-null if the `milestones_seen` insert succeeded (or would succeed — `onConflictDoNothing` handles retry safety). Client does not need separate seen-tracking.

### BirdSprite

**Condition:** Rendered when `habitatState.level >= 10`.

**Fly-in animation:** Starts at `x = sceneWidth + 100`, eases to resting position `(sceneWidth * 0.75, sceneHeight * 0.30)` over 60 frames (~1s) using cubic ease-out. Triggered only when `isFirstAppearance` is true on mount (captured via `useRef` — never re-read from props).

**First appearance mechanism:** `HabitatCanvas` accepts optional `celebratingLevel: number | null` prop. When `celebratingLevel === 10`, `BirdSprite` mounts with `isFirstAppearance = true`. On subsequent page loads without `?celebrate=10` query param, `isFirstAppearance = false` and bird renders at rest position immediately.

**Resting position:** Upper-right area — `x: sceneWidth * 0.75`, `y: sceneHeight * 0.30`. Size: `sceneHeight * 0.08` (smaller than tiger at 18%).

**Asset:** `layer-bird` frame in `public/sprites/habitat.json`. A placeholder colored rectangle is sufficient for development; final art polish is separate.

**Animation pattern:** Follows `TigerSprite` exactly — `useTick` + `useCallback` wrapping (Pitfall 3 guard), `useRef` for animation state (no `setState` in tick), lazy `useState` initializer for starting position.

### Dashboard Language Breakdown (HAB-07)

**Location:** Below the `<h1>My Deck</h1>` in `DeckView`, `mt-1` spacing.

**Render condition:** Only rendered when `languageBreakdown.length > 0`. No empty state needed — the section simply does not appear when no cards are learned.

**Typography:** `text-sm text-muted-foreground` — 14px, weight 400, `hsl(0 0% 45%)`.

**Format:** `"French: 23 learned · Spanish: 10 learned · English: 4 learned"` — separator is ` · ` (U+00B7 middle dot with spaces). Languages shown in order returned from DB query (natural GROUP BY order, no enforced sort — acceptable for v1).

**Label map:** Uses `LANGUAGE_LABELS` already defined in `deck-view.tsx` (`en → "English"`, `fr → "French"`, `es → "Spanish"`). Fallback: raw language code if label not found.
