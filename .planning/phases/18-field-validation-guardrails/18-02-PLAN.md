Purity contract at the top of scripts/measure-cwv-lib.mjs (MUST be honored): no process.env, no network (fetch/puppeteer/lighthouse), no process.exit, no top-level await.

evaluateGates(medians, thresholds, baseline, driftPct = 15):
  - medians: Record<string, number> — a route's computeMedians() output (keys include lcp, tbt, cls, score)
  - thresholds: { lcp, tbt, cls, score } — absolute hard-fail gates (D-09; may be a per-route D-11 exception)
  - baseline: Record<string, number> | null — locked Phase 18 baseline medians for this route, or null (first run)
  - driftPct: number — drift-warning threshold (default 15, D-09)
  - returns: { hardFail: boolean, failures: string[], warnings: string[] }
  - hard-fail when: lcp > thresholds.lcp, tbt > thresholds.tbt, cls > thresholds.cls, score < thresholds.score
  - drift WARNING (never a failure) when a metric is (after-before)/before > driftPct/100 vs baseline

deriveExceptionGate(median, headroomPct = 15):
  - returns Math.round(median * (1 + headroomPct/100)); throws on non-finite median (getBundleKb fail-loud pattern)
</interfaces>
