<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env-var gate overrides → gate evaluation | An override decides whether a gate can fail; a malformed one could silently disable it |
| DATABASE_URL / session tokens → spawned children | Secrets threaded between orchestrator and child processes |
| local prod-build server | Orchestrator-managed server process must be torn down, not leaked |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-03b | Tampering (of the gate's own trustworthiness) | `GATE_LCP/GATE_TBT/GATE_CLS/GATE_PERF` env overrides | mitigate | `Number.isFinite()` validation on every resolved threshold before use; fail loud and abort (a `NaN` would make `median > NaN` always false, silently passing every gate). Mirrors measure-cwv's `ROUTES.length===0` fail-loud guard (ASVS V5). |
| T-18-02c | Information Disclosure | `DATABASE_URL`/session tokens passed to spawned measure-cwv/playwright children | mitigate | Pass secrets via `env` only (never argv, never console); log only routes/exit codes/emails — inherit the existing measure-cwv/qa-lib "never log tokens" discipline in the new script |
| T-18-07 | Denial of Service (leaked resource) | leftover `next start` server on port 3000 | mitigate | Kill the server child in a `finally` block regardless of pass/fail/throw (Pitfall 7) |
| T-18-08 | Tampering (supply chain) | new perf script imports | accept | No new dependency; imports only the import-safe local pure lib; never imports the env-guarded qa-lib/measure-cwv modules |
</threat_model>
