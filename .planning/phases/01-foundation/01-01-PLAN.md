    1. Create `src/db/index.ts` — Neon HTTP driver + Drizzle singleton:
       ```typescript
       import { neon } from "@neondatabase/serverless";
       import { drizzle } from "drizzle-orm/neon-http";
       import * as schema from "./schema";

       const sql = neon(process.env.DATABASE_URL!);
       export const db = drizzle({ client: sql, schema });
       ```
       Note: Uses `process.env.DATABASE_URL!` directly (not `env.ts`) because this file is imported by `auth.ts` which is imported at module scope — the env validation runs separately at app startup.

    2. Create `src/db/schema.ts` with ALL tables for all 6 phases. Use branded types for all ID columns.

       Branded type helper at top of file:
       ```typescript
       declare const __brand: unique symbol;
       type Brand<T, B> = T & { [__brand]: B };

       export type UserId = Brand<string, "UserId">;
       export type DeckId = Brand<string, "DeckId">;
       export type CardId = Brand<string, "CardId">;
       export type RecallEventId = Brand<string, "RecallEventId">;
       ```

       **Better Auth tables** — run `npx auth@latest generate --output src/db/auth-schema.ts` first, then merge into schema.ts. These tables MUST match Better Auth's expected shape. The generated tables are `user`, `session`, `account`, `verification`. Apply `.$type<UserId>()` to the user table's `id` column after merging.

       **App tables (all defined in Phase 1, populated in later phases):**

       `decks` table:
       - `id` text PK `.$type<DeckId>()` — nanoid generated
       - `userId` text NOT NULL, references `user.id` on delete cascade
       - `language` text NOT NULL — one of "fr", "es", "en"
       - `createdAt` timestamp NOT NULL default now()
       - `updatedAt` timestamp NOT NULL default now()
       - Unique constraint on `(userId, language)` — one deck per language per user

       `cards` table:
       - `id` text PK `.$type<CardId>()` — nanoid generated
       - `deckId` text NOT NULL, references `decks.id` on delete cascade
       - `front` text NOT NULL — word in native language
       - `back` text NOT NULL — translated word
       - `source` text NOT NULL — "manual" or "wordlist"
       - `recallCount` integer NOT NULL default 0
       - `lastStudiedAt` timestamp (nullable)
       - `createdAt` timestamp NOT NULL default now()
       - `updatedAt` timestamp NOT NULL default now()

       `recall_events` table:
       - `id` text PK `.$type<RecallEventId>()` — nanoid generated
       - `cardId` text NOT NULL, references `cards.id` on delete cascade
       - `correct` boolean NOT NULL
       - `createdAt` timestamp NOT NULL default now()

       `milestones_seen` table:
       - `id` text PK — nanoid generated
       - `userId` text NOT NULL, references `user.id` on delete cascade
       - `milestone` text NOT NULL — e.g., "10", "25", "50", "100"
       - `seenAt` timestamp NOT NULL default now()
       - Unique constraint on `(userId, milestone)` — exactly-once guarantee

       `habitat_metadata` table:
       - `id` text PK — nanoid generated
       - `userId` text NOT NULL UNIQUE, references `user.id` on delete cascade
       - `lastActivityAt` timestamp NOT NULL default now()
       - `createdAt` timestamp NOT NULL default now()

       All foreign keys use `references(() => parentTable.id)` Drizzle syntax. All tables use `pgTable()` from `drizzle-orm/pg-core`. Export every table and every branded type.

    3. Create `drizzle.config.ts`:
