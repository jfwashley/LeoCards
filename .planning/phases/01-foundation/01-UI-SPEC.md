# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui |
| Preset | warm — orange/amber primary, neutral-warm backgrounds |
| Component library | Radix UI (via shadcn) |
| Icon library | lucide-react |
| Font | Inter (system fallback stack: Inter, ui-sans-serif, system-ui, sans-serif) |

**shadcn initialization:** `npx shadcn@latest init` with the following `components.json` overrides:
- `tailwind.cssVariables: true`
- `tailwind.baseColor: "orange"` (maps to `--primary` in HSL warm orange)
- `style: "default"`

**Color variable mapping (CSS custom properties):**
- `--background`: warm white `hsl(30 20% 98%)` — slightly warm, not pure white
- `--card`: warm neutral `hsl(30 15% 96%)`
- `--primary`: orange `hsl(24 95% 53%)` — shadcn orange-500 equivalent
- `--primary-foreground`: `hsl(0 0% 100%)`
- `--muted`: `hsl(30 10% 92%)`
- `--destructive`: `hsl(0 84% 60%)`

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline label padding |
| sm | 8px | Input internal padding (vertical), button icon gap |
| md | 16px | Default element spacing, form field gap |
| lg | 24px | Card internal padding, form section gap |
| xl | 32px | Auth card max-width padding |
| 2xl | 48px | Vertical centering offset on auth pages |
| 3xl | 64px | Top margin on centered auth card |

Exceptions:
- Touch targets (buttons, links) minimum 44px height — sourced from WCAG 2.5.5 (default)
- Auth card fixed width: `max-w-sm` (384px) on mobile, centered on desktop

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 400 (regular) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 28px | 600 (semibold) | 1.15 |

Notes:
- Display is used for the "TioCards" wordmark and the auth page tagline "Your tiger is waiting." only
- Heading (20px/600) is used for the form heading — e.g., "Create your account" / "Welcome back"
- Body (16px/400) is used for all form inputs, inline error messages, and supporting text
- Label (14px/400) is used for field labels, helper text below fields, and "Forgot password?" link
- Tiger emoji rendered at 40px (font-size: 2.5rem) above the wordmark on auth pages — not an icon, rendered as text

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(30 20% 98%)` — warm white | Page background, auth page surface |
| Secondary (30%) | `hsl(30 15% 96%)` — warm card | Auth card background, form input backgrounds |
| Accent (10%) | `hsl(24 95% 53%)` — orange | CTA buttons, active link color, focus ring |
| Destructive | `hsl(0 84% 60%)` — red | Inline field error text, error icon |

Accent reserved for:
1. The single primary CTA button on each auth page ("Sign up", "Sign in", "Send reset link", "Set new password")
2. Focus ring on all interactive form elements (`ring-primary`)
3. Checked state if any checkbox appears (auth consent, future use)

Accent is NOT used for: headings, body copy, nav links, background decorations, or any secondary actions.

Secondary action links ("Forgot password?", "Already have an account?", "Back to login") use `text-muted-foreground` with `underline` on hover — not accent color.

## Pages and States in Scope

This phase delivers four pages and one stub. Each has defined states below.

### /login

| State | Behavior |
|-------|----------|
| Default | Email + password fields, "Sign in" CTA (accent), "Forgot password?" link (label size, muted), "Don't have an account? Sign up" link |
| Field error | Inline red text below the specific field that failed; field border shifts to destructive color |
| Loading | "Sign in" button shows spinner + disabled state; no full-page loader |
| Auth error | "Incorrect email or password." rendered below the password field — not a banner |

### /signup

| State | Behavior |
|-------|----------|
| Default | Name + email + password fields, "Create account" CTA (accent), "Already have an account? Sign in" link |
| Field error | Inline red text below the specific field; same pattern as /login |
| Loading | "Create account" button disabled + spinner |
| Success | Redirect to /dashboard (no intermediate confirmation page) |

### /forgot-password

| State | Behavior |
|-------|----------|
| Default | Email field only, "Send reset link" CTA (accent), "Back to sign in" link |
| Loading | Button disabled + spinner |
| Sent | Form replaced by confirmation message (see Copywriting below) |
| Error | Inline error below email field |

### /reset-password (password reset landing)

| State | Behavior |
|-------|----------|
| Default | New password + confirm password fields, "Set new password" CTA |
| Token invalid/expired | Error message + link back to /forgot-password |
| Success | Redirect to /login with no persistent state |

### /dashboard (stub)

| State | Behavior |
|-------|----------|
| Authenticated | Warm placeholder with user's name: "Your habitat is being built, [name]." — plain text, no images |
| Unauthenticated | Redirect to /login (handled by proxy.ts) |

## Interaction Contracts

### Form Inputs

- All inputs use shadcn `<Input>` component
- Placeholder text is hint-style, not label replacements — every field has a visible `<Label>` above it
- Error state: `border-destructive` + red helper text below field rendered by react-hook-form `<FormMessage>`
- No red borders until first submission attempt (not on blur for first interaction)
- After first submission: errors appear on blur per-field

### Buttons

- Primary CTA: shadcn `<Button>` variant `"default"` — uses `bg-primary text-primary-foreground`
- Loading state: spinner icon (lucide `Loader2` with `animate-spin`) replaces button text; button `disabled`
- Minimum height: 44px (Tailwind `h-11`)
- Full width on auth forms: `w-full`

### Auth Card Layout

- Centered vertically and horizontally on all screen sizes
- `max-w-sm` (384px) width
- Card has `rounded-xl` corners and `shadow-sm`
- Card padding: 24px (lg token) all sides
- Tiger emoji + wordmark + tagline stacked above the card, not inside it
- Stack gap between logo block and card: 16px (md token)

### Links

- "Forgot password?": positioned right-aligned below the password field, before the CTA button
- "Sign up" / "Sign in" crosslinks: centered below the CTA button
- All text links use `text-sm text-muted-foreground underline-offset-4 hover:underline`
