## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Drizzle migration → live Neon DB | DDL change adds a single nullable column to `cards`. Reviewed before apply; no DROP, no data DML. | Schema only — no row data. |
| Client (browser) → `POST /api/cards/[id]/pause` | Untrusted card id in URL path, untrusted session cookie in headers, no body. | Card id (string), session cookie (HTTP-only). |
| Client (browser) → `POST /api/cards/[id]/unpause` | Same as pause — id + cookie are the only client inputs. | Card id (string), session cookie (HTTP-only). |
| Route handler → Neon DB | Single UPDATE per endpoint; ownership inner-join enforces authz at the SQL layer (mirrors SEC-02 from Phase 7). | `pausedAt` and `cooldownUntil` timestamps. |
| Server-rendered `dashboard/page.tsx` → `<DeckView>` props | Server-side; no untrusted input crosses (session derives from Better Auth cookie validation before any DB read). | `Date \| null` per card. |
| Client `<CardList>` → POST /api/cards/[id]/{pause,unpause} | Re-uses the same client → route-handler boundary above; client component holds no privilege. | Card id (string). |

## Threat Register

| Threat ID | Category | Component | Disposition | Mitigation | Status |
|-----------|----------|-----------|-------------|------------|--------|
| T-12-01 | Tampering | DDL applied to shared Neon DB (Plan 12-01) | mitigate | Migration file inspected before apply; `drizzle/0002_first_slipstream.sql` is a single `ALTER TABLE "cards" ADD COLUMN "pausedAt" timestamp;` — no DROP, no data DML. Generated by drizzle-kit, not hand-written. | closed |
| T-12-02 | Denial of Service | ADD COLUMN on `cards` table (Plan 12-01) | accept | Postgres metadata-only operation on a nullable-without-default column. `src/db/schema.ts:106` confirms `pausedAt: timestamp("pausedAt")` (no `notNull`, no `.default()`). Premise holds. | closed |
| T-12-03 | Tampering | `computeUnpauseUpdate` math (Plan 12-02) | accept | Pure function over caller-supplied Dates; no `Date.now()`, no I/O. `src/lib/study-engine.ts:283-296` body uses only `now.getTime()` / `pausedAt.getTime()` / `cooldownUntil.getTime()`. 4 unit cases cover NULL / future / past / zero-duration in `src/lib/study-engine.test.ts:336-372`. | closed |
| T-12-04 | Information Disclosure | `getStudyCards` exposing paused-card existence (Plan 12-02) | accept | Paused cards filtered OUT at SQL layer — `src/lib/study-queries.ts:44` WHERE clause is `and(eq(cards.deckId, deckId), isNull(cards.pausedAt))`. Caller never sees them; nothing to leak. | closed |
| T-12-05 | Tampering | Writing to another user's card by guessing/forging the card id (Plan 12-03) | mitigate | Ownership enforced via `.innerJoin(decks, eq(cards.deckId, decks.id)).where(and(eq(cards.id, id as CardId), eq(decks.userId, session.user.id)))` in both `pause/route.ts:64-66` and `unpause/route.ts:68-70`. UPDATE gated on the post-SELECT `if (!owned)` check. Mirrors Phase 7 SEC-02. | closed |
| T-12-06 | Spoofing | Unauthenticated caller invoking the endpoint (Plan 12-03) | mitigate | `auth.api.getSession({ headers: await headers() })` in both routes (`pause/route.ts:38-41`, `unpause/route.ts:42-45`); null session returns 401 before any DB read. Better Auth handles session validation. | closed |
| T-12-07 | Denial of Service | Burst pause/unpause calls (scripted abuse, clicker DoS) (Plan 12-03) | mitigate | `createRateLimiter({ windowMs: 60_000, maxRequests: 30 })` declared at module scope in both endpoints (`pause/route.ts:15-18`, `unpause/route.ts:13-16`). 429 with `Retry-After` header returned on `!allowed`. 30/min/user — generous for legitimate burst, rejects scripted abuse. | closed |
| T-12-08 | Information Disclosure | Distinguishing "card does not exist" vs "card not owned" via error responses (Plan 12-03) | mitigate | Both cases return identical `403 { error: "Forbidden" }` in both routes (`pause/route.ts:69`, `unpause/route.ts:73`); never 404 on ownership failure. Existence is not leaked. | closed |
| T-12-09 | Tampering | Multi-statement race during unpause on a no-transaction driver (Plan 12-03) | mitigate | The write is exactly ONE UPDATE statement (row-level atomic on Postgres). `unpause/route.ts:94` is the only `db.update(cards)` call in the file (grep == 1). A concurrent pause/unpause on the same row sees one consistent linearisation; later request wins. | closed |
| T-12-10 | Tampering | Writing fields outside the pause/unpause contract (e.g. `lastStudiedAt`) (Plan 12-03) | mitigate | `lastStudiedAt` MUST NOT appear in the unpause SET clause. Verified: `grep -c 'lastStudiedAt' src/app/api/cards/[id]/unpause/route.ts` == 0. Analytics correctness depends on this. | closed |
| T-12-11 | Tampering | Client forging card id in the fetch URL (Plan 12-04) | mitigate | All authority server-side via T-12-05. `src/components/card-list.tsx:30-55` `togglePause` POSTs to `/api/cards/${card.id}/${action}` with no client-side authority assertion; cross-user guess returns 403 with no state change. | closed |
| T-12-12 | Information Disclosure | Logging card ids / pause state to the console (Plan 12-04) | accept | `card-list.tsx:41-43` logs only HTTP status: `` `Pause toggle failed (${res.status}); state will resync on next refresh` `` — no card content, front/back, id, or `pausedAt` timestamp. Line 46 logs `"Pause toggle network error"` + Error object — no card payload. Premise holds. | closed |
| T-12-13 | Denial of Service | Click-storm pausing many cards rapidly (Plan 12-04) | mitigate | Server-side 30/min/user limit (T-12-07) + per-card client-side `pendingCardIds: Set<string>` in `card-list.tsx:25-27` (add on click line 31, remove in `finally` lines 48-52). `disabled={pendingCardIds.has(card.id)}` on Button at line 192 (desktop) and 261 (mobile). | closed |
| T-12-14 | Accessibility (tracked here for completeness) | Pause button keyboard reachability (Plan 12-04) | mitigate | Reuses `<Button variant="ghost">` shadcn primitive (keyboard-focusable). `aria-label` + `title` set per state ("Resume this card" / "Pause this card") on both desktop (`card-list.tsx:186-191`) and mobile (`:257-260`). | closed |
| T-12-15 | n/a (verification artifact) | E2E spec — `e2e/12-pause-cards.spec.ts` (Plan 12-05) | accept | Test code holds no secrets; helpers (`signUpWithDeck`, `addWordsFromBrowser`) use the standard test-account flow already used by Phases 6, 9, 11. | closed |
| T-12-SC | Supply Chain | npm/pip/cargo installs across all 5 plans | accept | Zero new packages added in Phase 12. `package.json` dependency tree unchanged from pre-Phase-12 baseline. All primitives (`lucide-react`, `better-auth`, `drizzle-orm`, `vitest`, `playwright`, in-repo `src/lib/rate-limit.ts`) pre-existed. No slopcheck required. | closed |
