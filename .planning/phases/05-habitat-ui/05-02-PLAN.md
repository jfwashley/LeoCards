   - Level 9+: add "layer-animal-2"

   - Returns -1 (left) or 1 (right) randomly (per D-05)

     - "crossfade": Render two `<pixiSprite>` elements (old texture + new texture). Animate old sprite alpha from 1 to 0 and new sprite alpha from 0 to 1 over 30 frames (~0.5s). Use `useTick` with `useCallback` to update alpha refs per-frame (avoid setState in useTick per Pitfall 3).
     - "none": Instant texture swap, no animation.

     - Mid-ground layers: `mouseX * sceneWidth * 0.05` (5% shift)
     - Foreground: no shift (anchored)
   - Each layer renders as `<pixiSprite texture={sheet.textures[layerName]} x={offsetX} y={0} width={sceneWidth} height={sceneHeight} alpha={layerAlpha} />`
