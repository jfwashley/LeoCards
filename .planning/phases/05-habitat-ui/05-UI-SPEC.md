Accent (`--primary` orange) is reserved for:
- Level badge background on the full /habitat page overlay

The canvas interior (savanna scene) uses warm golden savanna tones (yellows, greens, earth tones) defined in sprite assets — these are not CSS design tokens but must harmonize with the warm orange brand palette.

## Interaction Contract

### Canvas Loading Sequence

1. Page mounts. Server component shell renders immediately with page chrome (nav, heading).
2. `next/dynamic` with `{ ssr: false }` triggers — `HabitatLoadingSpinner` shown (D-18).
3. PixiJS initializes, `Assets.load()` fetches sprite atlases, `GET /api/habitat` fetches habitat state.
4. On success: canvas fades in over 0.5s using Motion `animate` on opacity (D-19). Spinner exits.
5. On API error: error state card shown with retry button (D-23).
6. On offline (navigator.onLine false, fetch fails): read `localStorage` key `leocards_habitat_cache`, render stale data with offline banner (D-24).

### Tiger Mood Transitions

- Happier shift (sad→neutral, neutral→happy, any→excited): sprite swap + bounce animation via Motion `spring` (D-06).
- Sadder shift (happy→neutral, neutral→sad, excited→happy/neutral/sad): crossfade blend ~0.5s via Motion opacity tween (D-06).
- Excited state: bounce loop + sparkle particle burst from `SparkleParticles` component. Loop continues while mood === "excited" (D-07).
- Tiger position: one of three x-positions chosen randomly on mount (center-bottom, 30%-left, 75%-left). Direction (left/right facing) also random. No animation on position — instant placement (D-04, D-05).

### Habitat Level Layers

- Level 1: bare grass layer + single tree sprite. Minimal starter scene (D-12).
- Levels 2–10: additive sprite layers appear as `HabitatState.level` increases (D-09).
- Level-up event: new layer elements fade in with `scale(0.8) → scale(1)` pop over 0.6s (D-20). Celebration overlay text "Level {N}!" appears simultaneously.
- Decay visual: element layers fade out (opacity reduced) as quality drops below threshold. Proportional to how many levels worth of decay has occurred (D-13).

### Parallax

- 3 depth layers: background (distant hills/sky at 20% scroll parallax factor), mid-ground (scene elements at 50%), foreground (grass at 100%). Values are Claude's discretion (CONTEXT.md).
- Parallax driven by mouse position on desktop, device tilt (if available) on mobile, else static.

### Tab Visibility

- On `visibilitychange` → hidden: `app.ticker.stop()` (D-22).
- On `visibilitychange` → visible: `app.ticker.start()`.

### Mini Widget

- Renders inside an existing shadcn `Card` on the dashboard page.
- 80px tall PixiJS canvas showing tiger sprite (current mood) + habitat background thumbnail.
- Below canvas: CSS progress bar (shadcn-styled) showing progress toward next level. Label: "Level {N} — {current}/{threshold} cards".
- Entire card is a Next.js `<Link href="/habitat">` for navigation (D-16).
- Minimum tap target: 44px (card is 80px + padding, satisfies requirement).

## Animation Timing Reference

| Animation | Duration | Easing | Trigger |
|-----------|----------|--------|---------|
| Scene fade-in | 0.5s | ease-out | Assets loaded |
| Mood bounce (happier) | 0.4s | spring (stiffness 300, damping 20) | Mood state change |
| Mood crossfade (sadder) | 0.5s | ease-in-out | Mood state change |
| Excited sparkle loop | continuous while excited | — | mood === "excited" |
| Level-up element pop | 0.6s | ease-out with scale 0.8→1 | Level threshold crossed |
| Level-up text display | 2.0s visible, 0.5s fade-out | ease-in | Level threshold crossed |
| Offline banner fade-in | 0.3s | ease-out | Fetch fails + cached data found |
