## Milestone Goal

Let users upload a photo, have Claude vision extract the vocabulary words, review/edit the results, and add the kept words (auto-translated via the existing DeepL pipeline) into a chosen deck. Image feature only — no art pass.

## Phases

## Key Accomplishments

- **Image-to-flashcards pipeline end-to-end:** Pick → validate → preview → extract via Claude vision → review & edit → DeepL-translate → commit to deck — all working in code with 1773 unit tests green.
- **Protected vision endpoint:** `/api/extract` gated by Better Auth session, in-memory rate-limited (10 req/min), server-side magic-byte type guard (JPEG/PNG/WEBP subtype-verified), bounded content-length, secure failure paths, no PII logged. Built on Vercel AI SDK v6 + `@ai-sdk/anthropic` v3 with `claude-sonnet-4-6` (verified current 2026-05-19).
- **Batched commit on Neon no-tx with continue-on-failure:** `saveImageCards` server action with bounded array (max 100), per-field validation, combined-WHERE ownership check, and per-row failure path that preserves successful inserts.
- **Same-language dedupe segregation:** Review list flags words already present in the same-language deck back-words, segregating duplicates from new entries without blocking the commit.
- **Code-review hardened post-fix:** 20 findings across the 3 phases all resolved (8 Warning, 12 Info / advisory). Notable: WEBP magic-byte subtype check, server/client image-size constants unified, BCP-47 regex on `targetLanguage` (prompt-injection mitigation), `saveImageCards` length + field caps + ownership in one WHERE.
- **Threat models verified in code:** 32 STRIDE threats across 3 SECURITY.md artifacts, every CLOSED threat cited with file:line evidence.
