## Phase Details

### Phase 19: Daybreak Foundation + Onboarding & Auth
**Goal**: The Daybreak design system is live app-wide and every auth/onboarding screen matches the hi-fi mocks. **Requirements**: DSY-01/02/03, ONB-01..06. **Plans**: 5 (3 waves) — 19-01 primitives + tokens/fonts; 19-02 Login/Signup; 19-03 Forgot/Reset; 19-04 welcome 3-step flow; 19-05 empty states.

### Phase 20: Study Screen
**Goal**: Study card + session-result screen redesigned to Daybreak, preserving the study engine + QA badge. **Requirements**: STU-01/02. **Plans**: 2 (2 waves) — 20-01 study card + ghost-peek stack; 20-02 session chrome + end screen + level-up overlay.

### Phase 21: Dashboard — "My Deck"
**Goal**: Full Dashboard (header, habitat hero medallion, action line, "Your words" accordion) redesigned to Daybreak across all seven states. **Requirements**: DSH-01..07. **Plans**: 5 (2 waves) — 21-01 Popover wrapper; 21-02 TopBar + deck picker; 21-03 HabitatMedallion/Hero; 21-04 action line (Browse removed); 21-05 "Your words" accordion + edit modal.

### Phase 22: Add a Card
**Goal**: Type-a-word + from-an-image flows redesigned to Daybreak, preserving translation/extraction pipelines. **Requirements**: ADC-01/02/03. **Plans**: 4 (3 waves) — 22-01 atoms + LangChip; 22-02 type-a-word; 22-03 image Pick/Confirm/Extract; 22-04 Review/Translate/Result.

### Phase 23: Browse Words
**Goal**: Topic-tiles landing + per-topic word list (CEFR filtering) redesigned to Daybreak with optimistic add/remove. **Requirements**: BRW-01..04. **Plans**: 4 (3 waves) — 23-01 BWMedallion icons; 23-02 Browse entry link; 23-03 two-screen IA + re-skin; 23-04 e2e retargets.

### Phase 24: Habitat
**Goal**: Habitat re-skinned as a living Daybreak experience — kept pre-rendered video with Daybreak overlays (mood/decay tint, chrome, bottom progress card), 3-tier motion, reduced-motion safety, all 8 state boards. (Scope per 24-CONTEXT.md: keep the video, re-skin overlays only.) **Requirements**: HAB-01..05. **Plans**: 3 (3 waves) — 24-01 constants/moodTint/keyframe + test scaffold; 24-02 6 Daybreak atoms + CSS-only celebration; 24-03 scene integration + mobile-freeze + ?celebrate hardening + e2e retargets.
