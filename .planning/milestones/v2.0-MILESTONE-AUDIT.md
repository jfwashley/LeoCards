## 5. Tech Debt (full detail in YAML frontmatter)

**Phase 11 shipping-risk (recommend `/gsd-code-review-fix 11` before real users):**
- WR-01 unbounded `saveImageCards` input (security/DoS) — auth'd attacker can fire ~10k sequential inserts in one call. **Concrete fix: cap to 100 items + per-item trim/non-empty/max-length pre-loop.**
- WR-04 zero direct unit tests for `saveImageCards` (the batch-commit server action).
- WR-03 commit-orchestration test mocks use wrong shape; a dual-shape shim papers over it.
- WR-02 `handleNext`/`handleCommit` lack outer try/catch — UI can stick on a spinner.

**Phase 10 security-adjacent (recommend `/gsd-code-review-fix 10`):**
- WR-02 WebP magic-byte only checks `RIFF`, not `WEBP` subtype → EXT-05 partial type-guard bypass.
- IN-01 no BCP-47 regex on `targetLanguage` → cheap prompt-injection mitigation.
- env.ts robustness — empty-string `ANTHROPIC_API_KEY` bricks the whole app instead of degrading to 503 (caught live during env prep).

**Missing security artifacts:** No `10-SECURITY.md` or `11-SECURITY.md` generated — both phases introduced real server attack surface. Recommend `/gsd-secure-phase 10` and `/gsd-secure-phase 11`.
