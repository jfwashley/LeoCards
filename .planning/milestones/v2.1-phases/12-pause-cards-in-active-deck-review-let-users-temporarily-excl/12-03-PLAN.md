## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client (browser) → POST /api/cards/[id]/pause | Untrusted card id in URL path; untrusted session cookie in headers; no body. |
| Client (browser) → POST /api/cards/[id]/unpause | Same as pause — id + cookie are the only client inputs. |
| Route handler → Neon DB | Single UPDATE per endpoint; ownership join enforces authz at the SQL layer. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-05 | Tampering | Writing to another user's card by guessing/forging the card id | mitigate | Ownership enforced via `innerJoin(decks).where(eq(decks.userId, session.user.id))` — the UPDATE only fires after a SELECT proves the (card → deck → user) chain. Mirrors SEC-02 from study/complete (Phase 7 verified). |
| T-12-06 | Spoofing | Unauthenticated caller invoking the endpoint | mitigate | `auth.api.getSession({ headers: await headers() })` — null session → 401 before any DB read; Better Auth handles session validation. |
| T-12-07 | Denial of Service | Burst pause/unpause calls (e.g. clicker DoS, scripted abuse) | mitigate | `createRateLimiter({ windowMs: 60_000, maxRequests: 30 })` per user; 429 with Retry-After. 30/min is generous for legitimate burst use (a user pausing 10 cards in a deck review) but rejects scripted abuse. |
| T-12-08 | Information Disclosure | Distinguishing "card does not exist" vs "card not owned" via error messages | mitigate | Both cases return identical 403 `{ error: "Forbidden" }` — never reveal existence (Tamper-safe / cf. study/complete error contract). |
| T-12-09 | Tampering | Multi-statement race during unpause (read cooldownUntil → compute → write) on a no-transaction driver | mitigate | The write is ONE UPDATE statement (row-level atomic on Postgres). A concurrent pause/unpause on the same row will see one consistent linearisation; the worst-case outcome is benign (the later request "wins"). Documented in code via Pitfall reference. |
| T-12-10 | Tampering | Writing fields outside the pause/unpause contract (e.g. lastStudiedAt) | mitigate | `lastStudiedAt` MUST NOT appear in the unpause SET clause (Pitfall 4); explicit grep gate in <done>. Analytics correctness depends on this. |
| T-12-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages (12-RESEARCH.md § "Package Legitimacy Audit"). No slopcheck required. |
</threat_model>
