### Added — gesture-gate primitive

```ts
export function setupGestureGate(opts: SetupGestureGateOpts): () => void
```

- Listens on `document` for `pointerdown` / `touchstart` / `keydown` / `wheel`.
- Listens on `window` for `scroll` (scroll does not bubble from window → document).
- First firing event invokes `onGesture()` exactly once, then synchronously detaches every listener.
- `reducedMotion: true` → returns a no-op cleanup; attaches ZERO listeners. R4 hard lockout.
- Passive listeners throughout (`{ passive: true }`).
- No `requestIdleCallback`. No `setTimeout` mount fallback.

### Gesture-mount logic — listed events

| Target     | Event          | Notes                                                |
|------------|----------------|------------------------------------------------------|
| `document` | `pointerdown`  | mouse + pen + touch primary path                     |
| `document` | `touchstart`   | iOS Safari fallback when pointer events disabled     |
| `document` | `keydown`      | keyboard-first users                                 |
| `document` | `wheel`        | scroll wheel without page scroll (trackpad-y users)  |
| `window`   | `scroll`       | scroll does NOT bubble window → document             |

All listeners are `{ passive: true }` and detach atomically on the first qualifying event.

### Reduced-motion path

```
usePrefersReducedMotion() === true
  → setupGestureGate({reducedMotion:true}) is called by the effect, but it
    returns a no-op cleanup having attached zero listeners.
  → canvasMounted = (snapshotMode || (!true && gestured)) = snapshotMode
  → In production, snapshotMode === false (NODE_ENV gate), so canvasMounted is
    false forever. Wrapper renders <Image> only. No tabIndex. No keyboard
    orbit affordance.
```

### CLS = 0 evidence

Wrapper element carries intrinsic size BEFORE either child paints:

```jsx
<div style={{
  aspectRatio: "16/9",
  maxHeight: "min(70vh, 400px)",
  position: "relative",      // NEW — creates positioning context
}}>
  <Image fill ... style={{ objectFit: "cover", transition: "opacity 200ms", opacity: canvasMounted ? 0 : 1 }} />
  {canvasMounted && <canvas style={{ position: "absolute", inset: 0, ... }} />}
</div>
```

- The wrapper's box dimensions are determined entirely by CSS (`aspectRatio` + `maxHeight`) — no JS measurement, no waterfall.
- `<Image fill>` is absolutely positioned by next/image's own wrapper.
- The `<canvas>` is `position: absolute; inset: 0`.
- Result: when `canvasMounted` flips from `false` → `true`, the wrapper's bounding box does not change. The poster fades to opacity 0 while the canvas paints over the same absolute region. **Zero layout shift.**

Existing Phase 13 R6 acceptance unit (`13-habitat-3d.spec.ts` R4 / R5) already implicitly validates this: those tests would fail with reflow-based assertions if the swap moved geometry.
