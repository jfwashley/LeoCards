<objective>
Add the R5 mount-hint affordance. After Plan 02's poster paints, if the user
has not interacted within 2000 ms, a subtle "Tap to animate" overlay fades in.
First gesture (or canvas mount) hides it instantly. Reduced-motion users
never see the hint.

Purpose: R5 — make the gesture-gate discoverable without compromising the
gesture-only mount contract from R3. The hint MUST NOT itself trigger the
canvas mount; it is a passive overlay that the user dismisses by gesturing.

Output: hint overlay added to `habitat-3d-canvas.tsx` (small additive change
to Plan 02's shell). Three unit tests covering timing, dismissal, and
reduced-motion suppression.
</objective>

    4. Render the hint inside the wrapper, as a sibling of the poster + canvas:
       ```tsx
       {!reducedMotion && hintVisible && !canvasMounted && (
         <div
           data-testid="habitat-canvas-hint"
           aria-hidden="true"
           style={{
             position: "absolute",
             bottom: "8%",
             left: "50%",
             transform: "translateX(-50%)",
             padding: "0.25rem 0.75rem",
             borderRadius: "9999px",
       ```
