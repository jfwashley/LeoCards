<objective>
Port the dashboard mini-widget canvas from PixiJS to Three.js. The widget
shows the user's current level at 80px, slowly auto-orbiting, with NO
user-driven orbit (no drag, no keyboard — distinct from the full-page
canvas).

Use the SAME `src/lib/habitat-3d/` modules from Plan 02 — no scene-graph
fork. The widget differs from the full canvas in three ways only:

1. Smaller renderer size (80×80 instead of viewport-scaled)
2. `attachOrbit` configured with `autoSpeed * 0.5` (slower) and the
   user-drag listeners disabled (or simply not attached — the widget is
   inside a `<Link>` so click-to-navigate per Phase 5 D-16 must work)
3. No HUD overlay (level badge + mood label live in the parent
   `<HabitatWidget>` shell, not inside the canvas)

This plan does NOT decide live-vs-cached — that's Plan 06's perf gate
(D-28). This plan SHIPS the live-3D widget; Plan 06 measures it and
either keeps it or swaps to a cached `<img>` based on results.

Purpose: closes the live-3D arm of D-28 by shipping it; Plan 06 closes
the cached-image arm if measurement requires it.

Output:

</objective>
