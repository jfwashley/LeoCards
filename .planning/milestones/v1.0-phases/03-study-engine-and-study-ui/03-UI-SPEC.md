## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, dot spacing in progress dots |
| sm | 8px | Compact element spacing, card stack offset (8px per layer) |
| md | 16px | Default element spacing, card content padding |
| lg | 24px | Section padding, card face vertical padding |
| xl | 32px | Layout gaps, card face horizontal padding |
| 2xl | 48px | Major section breaks, session end screen vertical rhythm |
| 3xl | 64px | Page-level spacing, full-screen study vertical centering |

Exceptions:
- Touch targets for swipe-to-grade: minimum 44px height (accessibility minimum for tap targets — applies to the active card area)
- Card stack layer offset: 8px (sm) per layer, capped at 3 visible layers (24px total stack depth)
- Progress dots: 8px diameter circles with 4px gaps

- Swipe left (still learning): Brief `bg-red-50` wash on card, 150ms, then card exits.

## Focal Point

Primary study screen focal point: the active flashcard face is the single visual anchor — it occupies the horizontal center of the viewport at a fixed vertical midpoint (`top: 40%`), all other chrome (deck label, quit button, progress dots) is muted and pushed to edges so the eye lands on the card word first.

## Interaction Contract

### Flashcard Flip (D-09)

- Trigger: tap anywhere on card face
- Animation: CSS 3D perspective flip, `rotateY(180deg)`, duration 300ms, ease `cubic-bezier(0.4, 0, 0.2, 1)`
- The front face shows the word being tested. The back face (revealed) shows the translation.
- Flip is one-way per card turn — tapping again does not flip back. User must grade to proceed.
- Implementation: Motion `motion.div` with `rotateY` animation; `backface-visibility: hidden` on both faces.

### Swipe-to-Grade (D-11)

- Gesture: horizontal drag via Motion `drag="x"` prop on the active card
- Threshold: |offset.x| > 80px OR |velocity.x| > 500 triggers grade; below threshold, card snaps back
- Swipe right: grade = correct. Swipe left: grade = still learning.
- Visual feedback during drag: card rotates slightly (`rotate` tied to `x` offset, max ±12deg)
- On threshold crossed: swipe-off animation (card exits at 400ms with opacity fade), next card animates in from stack
- The card must be in the revealed state (flipped) before swipe gesture is enabled. Dragging a face-down card is ignored.
- Swipe-enable delay: 300ms after flip completes before swipe gesture activates (prevents reflex grading — per roadmap STUDY-02 guard)

### Card Stack Visual (D-13)

- Behind the active card: up to 3 card-shaped divs, each offset 8px down and 0px horizontal
- Each layer has `opacity: 0.6, 0.35, 0.15` (front-to-back)
- When total remaining cards > 3: always show exactly 3 layers. When total = 3: show 2 layers behind. When total = 2: show 1 layer. When total = 1: show 0 layers (active card only).
- Layer count updates after each grade (card removed from queue)
- No numbers, no progress bar — the thinning stack is the only progress signal

### Mastery Progress Dots (D-15)

- 3 dots per card row in `CardList`
- Filled dot (`●`, `bg-primary`): completed mastery round
- Empty dot (`○`, `border-border`): not yet completed
- Dot size: 8px diameter circle, `gap-1` (4px) between dots
- Placement: right side of card row, vertically centered

### Study Button Disabled State (D-07)

- When all cards are in cooldown: `<Button disabled>` with text "Next cards in Xh Ym"
- Countdown text format: `Xh Ym` (e.g., "4h 23m", "0h 45m"). If under 1 minute: "Next cards in <1m".
- Refresh interval: countdown text recomputes every 60 seconds via `setInterval` in the component
- When at least one card is due: `<Button>` with text "Start studying" (primary variant, full accent color)

### Session End Screen (D-19, D-20, D-21)

- Layout: centered column, `gap-8` (32px) between sections
- Tiger emoji: 🐯 at `text-6xl` (64px), always present, no conditional rendering
- Stats layout: 3 stat blocks in a row, each with a large number (Display 28px/600) and a label below (Label 14px/400)
  - "X studied" / "X% correct" / "X learned"
- CTA: single Button, primary variant: "Back to deck" — navigates to `/dashboard?deck={deckId}`

### Quit Session (D-04)

- A "Quit session" button is always visible during the session (top-right corner, ghost/muted variant)
- Tapping "Quit session" shows a confirmation: "Quit session? Your progress so far will be saved."
- Confirmation uses a simple inline text + two buttons (Continue studying / Quit and save) — not a Dialog, to keep the full-screen feel undisrupted
- "Quit and save" commits all grades collected so far, then navigates to `/dashboard?deck={deckId}`
- Destructive color (`--destructive`) is NOT used here — quitting is not destructive (progress is saved)

## Animation Contract

All animations use Motion 12 (`motion/react`). No CSS keyframe animations for interactive elements.

| Animation | Library | Duration | Easing | Trigger |
|-----------|---------|----------|--------|---------|
| Card flip (reveal) | Motion `animate` on `rotateY` | 300ms | `cubic-bezier(0.4, 0, 0.2, 1)` | Tap card |
| Swipe-off (correct) | Motion `animate` exit: `x: 400, opacity: 0` | 250ms | `easeIn` | Swipe right past threshold |
| Swipe-off (still learning) | Motion `animate` exit: `x: -400, opacity: 0` | 250ms | `easeIn` | Swipe left past threshold |
| Card snap-back | Motion spring: `type: "spring", stiffness: 300, damping: 30` | automatic | spring | Drag released below threshold |
| Card drag rotate | `rotate` = `x * 0.05`, clamped ±12deg | real-time | n/a | While dragging |
| Next card entrance | `scale: 0.95 → 1.0, opacity: 0.8 → 1.0` | 200ms | `easeOut` | After previous card exits |
| Stack layer resize | no animation — instant recalculation | — | — | After grade committed |
| Session end entrance | `opacity: 0 → 1, y: 16 → 0` | 400ms | `easeOut` | Session state transitions to "complete" |

## Accessibility Contract

- Swipe gesture is keyboard-accessible: `ArrowRight` = correct, `ArrowLeft` = still learning (applied to the active card `div` with `role="button"` and `tabIndex={0}`)
- Card flip is keyboard-accessible: `Enter` or `Space` on the card face triggers reveal
- Quit button has `aria-label="Quit study session"`
- Progress dots have `title="Round X of 3 complete"` on each filled dot and `title="Round X of 3 not yet complete"` on empty dots
- Touch targets: card occupies full usable width; swipe gesture area is the full card surface (min 44px height enforced by card min-height: 200px)
- The disabled Study button has `aria-disabled="true"` and `title` containing the full countdown text
