**Step 2: Create `src/components/study-session.tsx`** ("use client")

Session state machine using `useReducer`. This is the largest component.

**State type:**
```typescript
type SessionPhase =
  | { phase: "studying"; queue: SessionCard[]; currentIndex: number; graded: GradeEntry[]; flipped: boolean; swipeReady: boolean; lastGradeDirection: "left" | "right" | null; showQuitConfirm: boolean }
  | { phase: "looping"; queue: SessionCard[]; graded: GradeEntry[]; stillLearningCards: SessionCard[] }
  | { phase: "committing"; graded: GradeEntry[] }
  | { phase: "end"; stats: SessionStats }
  | { phase: "error"; message: string; graded: GradeEntry[] };
```

**Actions:** FLIP_CARD, ENABLE_SWIPE, SWIPE_GRADE, TOGGLE_QUIT_CONFIRM, QUIT_SESSION, COMMIT_DONE, COMMIT_ERROR, RETRY_COMMIT

**Reducer rules:**
- `FLIP_CARD` (only when phase=studying and !flipped): set flipped=true. Start a 300ms setTimeout in the component (via useEffect watching flipped) to dispatch ENABLE_SWIPE.
- `ENABLE_SWIPE`: set swipeReady=true.
- `SWIPE_GRADE` (only when swipeReady=true): push grade entry (cardId, direction from current card's stage, correct = direction === "right"). Set lastGradeDirection. Advance currentIndex. If currentIndex >= queue.length: check if any grades were "still learning" — if yes, re-queue those cards (D-03) by transitioning to "looping" phase, then back to "studying" with the re-queued cards. If no still-learning cards remain: transition to "committing".
- In "committing" phase: a useEffect fires the fetch to POST /api/study/complete. On success: compute stats and transition to "end". On error: transition to "error".
- `TOGGLE_QUIT_CONFIRM`: toggle showQuitConfirm boolean.
- `QUIT_SESSION`: transition to "committing" (commits all grades so far, per D-04).
- `COMMIT_ERROR`: transition to "error" with message.
- `RETRY_COMMIT`: transition back to "committing" to retry the fetch.

**Props:** `{ initialCards: SessionCard[]; deckId: string }`

**Layout (during studying phase):**
- Full-screen: `min-h-screen bg-background flex flex-col`
- Top bar: small "Studying: {deckId not shown — just 'Study session'}" label (Label 14px/400, text-muted-foreground) left-aligned, "Quit session" button (ghost variant, `aria-label="Quit study session"`) right-aligned. Horizontal padding matches xl (32px = `px-8`).
- Center area: flex-1 with items-center justify-center. Contains the card stack + active card.
- Quit confirmation (when showQuitConfirm): inline below the quit button — text "Quit session? Your progress so far will be saved." with two buttons: "Keep studying" (outline) and "Save and quit" (default). Not a Dialog.

**Layout (committing phase):**
- Simple centered spinner or "Saving your progress..." text.

**Layout (error phase):**
- Centered error message: "Couldn't save your progress. Check your connection and try again."
- "Retry saving session" button (primary variant).

**Layout (end phase — SessionEndScreen inline):**
- Centered column, `gap-8` (32px).
- Tiger emoji: `<span className="text-6xl">🐯</span>` (64px).
- Heading: "Great work, keep it up!" (Heading 20px/600, text-foreground).
- Stats row: 3 blocks in a `flex gap-8` row, each with large number (Display 28px/600, text-foreground) and label below (Label 14px/400, text-muted-foreground).
  - "{cardsStudied} studied" / "{Math.round(correctCount/cardsStudied*100)}% correct" / "{newlyLearned} learned"
  - The "learned" count uses `text-primary` (accent color) for highlight.
- CTA: `<Button variant="default">` with text "Back to deck", navigates to `/dashboard?deck=${deckId}` via `router.push()`.
- Entrance animation: `motion.div` with `initial={{ opacity: 0, y: 16 }}` `animate={{ opacity: 1, y: 0 }}` `transition={{ duration: 0.4, ease: "easeOut" }}`.

**Swipe hint (first card only):**
- On the very first card of the session, after the card is flipped, show a small text below the card: "Swipe right if correct, left if still learning" (Label 14px/400, text-muted-foreground). Hide after first swipe.

**Step 3: Create `src/components/study-card.tsx`** ("use client")

Single flashcard with 3D flip and swipe-to-grade.

**Props:**
```typescript
interface StudyCardProps {
  card: SessionCard;
  flipped: boolean;
  swipeReady: boolean;
  onFlip: () => void;
  onGrade: (direction: "left" | "right") => void;
  exitDirection: "left" | "right" | null; // set when card is being dismissed
}
```

**3D Flip implementation:**
- Outer container: `div` with `style={{ perspective: 1000 }}`, relative positioning.
- Two `motion.div` children stacked absolutely:
  - Front face: `animate={{ rotateY: flipped ? 180 : 0 }}`, `transition={{ duration: 0.3, ease: [0.4, 0, 0.2, 1] }}`, `style={{ backfaceVisibility: "hidden", transformStyle: "preserve-3d" }}`.
  - Back face: same animation but starts at `rotateY(-180)` and flips to 0. Same transition. Absolutely positioned over front.
- Both faces: `bg-card border border-border rounded-xl min-h-[200px] w-full max-w-sm` (card surface per UI-SPEC color). Padding: `px-8 py-6` (xl horizontal, lg vertical). Centered text.
- Front face content: word being tested at Display size (28px/600 = `text-[28px] font-semibold`), plus direction prompt below at Label size (14px/400 = `text-sm text-muted-foreground`): "What's the translation?" if stage=n2t, "What does this mean?" if stage=t2n. Also "Tap to reveal" hint at bottom.
- Back face content: the answer at Display size, plus direction label.
- Which word is "front" vs "back" depends on stage: if stage="n2t", show card.front (native) on front face and card.back (target) on back face. If stage="t2n", show card.back (target) on front face and card.front (native) on back face.
- onClick on the container (only when !flipped): call onFlip().

**Swipe implementation:**
- Wrap the card in `motion.div` with:
  - `drag={swipeReady ? "x" : false}` (disable drag until flipped + 300ms)
  - `dragConstraints={{ left: 0, right: 0 }}`
  - `dragElastic={0.7}`
  - `onDragEnd={(_event, info) => { ... }}` — check velocity (>300) or offset (>80px) per UI-SPEC
  - During drag: `style={{ rotate: useTransform(x, [-200, 0, 200], [-12, 0, 12]) }}` — card tilts with drag.
  - Swipe color feedback: use `useTransform` on drag x to interpolate background color. Right drag > 40px: brief green-50 wash. Left drag < -40px: brief red-50 wash. Use `style={{ backgroundColor: bgColor }}` on an overlay div.
- Use `AnimatePresence` with `mode="popLayout"` in the parent (study-session) to animate card exit:
  - `exit={{ x: lastGradeDirection === "right" ? 400 : -400, opacity: 0, transition: { duration: 0.25, ease: "easeIn" } }}`
  - Key the motion.div by card.id + currentIndex to trigger AnimatePresence.
- Next card entrance: `initial={{ scale: 0.95, opacity: 0.8 }}` `animate={{ scale: 1, opacity: 1 }}` `transition={{ duration: 0.2, ease: "easeOut" }}`.

**Keyboard accessibility:**
- The card container has `role="button"`, `tabIndex={0}`.
- `onKeyDown`: Enter or Space (when !flipped) -> onFlip(). ArrowRight (when swipeReady) -> onGrade("right"). ArrowLeft (when swipeReady) -> onGrade("left").
