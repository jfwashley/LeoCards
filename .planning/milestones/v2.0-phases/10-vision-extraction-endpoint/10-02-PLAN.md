<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → /api/extract | Untrusted JSON body (base64 image, declared mimeType, deckId) crosses here |
| /api/extract → Anthropic | Image bytes + system prompt sent to a paid third-party vision API |
| image text → model | Text printed inside the uploaded image is attacker-controllable content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-03 | Spoofing | unauthenticated caller | mitigate | `auth.api.getSession` gate → 401 before any work (guard step 1) |
| T-10-04 | Denial of Service | oversized base64 body before the costly vision call | mitigate | Content-Length fast path + authoritative `ceil(image.length*3/4) > 7MB` → 413 BEFORE decode/vision call (D-11, guard steps 3 & 6) |
| T-10-05 | Spoofing/Tampering | spoofed `mimeType` (client field is forgeable) | mitigate | Server MIME allow-list + hand-rolled magic-byte signature sniff → 415 (D-10, guard steps 7–8) |
| T-10-06 | Elevation/DoS | rate/cost abuse of expensive paid vision API | mitigate | `createRateLimiter` at 10 req/60s/user → 429 + Retry-After (D-17, guard step 2), stricter than translate's 30 |
| T-10-08 | Tampering | prompt-injection via adversarial text inside the uploaded image | accept | Low stakes (attacker poisons only their own deck); blast radius bounded by schema (`words: string[]`, ≤50, ≤100 chars each) + `temperature: 0` + system constraint "ONLY words visibly present" (10-AI-SPEC Section 6). Revisit if decks become shared/multi-user. |
| T-10-09 | Information Disclosure | logging image bytes / extracted words (privacy) | mitigate | Catch-block logs metadata only; explicit prohibition on logging `image`/data-URL/`words` (10-AI-SPEC Section 7; REQUIREMENTS transient-processing). Asserted by grep in Task 2 acceptance criteria. |
| T-10-10 | Information Disclosure | ANTHROPIC_API_KEY exposure | mitigate | Key read only from server `env`, client instantiated inside handler after key-presence 503 gate, never at module scope (D-03, Pitfall 3) |
</threat_model>
